# 混合流動性環境的共享模型

這是[強弱窗口與流動性補償研究](QUEUE_MIXTURE.md)的延伸。前輪對每個固定補償係數各自訓練，不能直接回答一組共享權重能否處理每天不同的流動性環境。本輪讓各股票／日期的窗口先抽取流動性係數，再由同一組固定十檔權重預測；每天全部50檔仍完整發報，保留平盤、弱窗口、缺報回退及外部轉移失敗。

## 事先固定的設計

`configs/intraday_queue_heterogeneous.json`固定三個種子17／29／43、600個訓練日期、200個校準日期及1000個測試日期。每天10:00預測30秒後的原始中間價方向；沿用目前盤中較保守的計分：平盤不獲漲跌得分。這不等同原日線的上漲／非上漲定義，不能互換成績。

流動性係數`r`在每個100秒歷史加30秒未來窗口開始前抽取，整個窗口固定；候選模型不能讀取`diagnostic_liquidity_response`或強弱標記。它使用與訂單事件及強弱狀態分開的既有過去亂數座標，不使用未來抽樣。相同`r`的混合窗口必須與對應固定係數世界的特徵、答案逐列一致。

|情境|事先指定的條件|
|---|---|
|equal_worlds|`r=[0,0.5,1,1.5]`，各25%|
|mostly_informative|同四種係數，機率45%／35%／15%／5%|
|mixed_weak_windows|上述機率，強壓力窗口機率另降至80%|
|feed_outage|上述機率，另有25%日期共同輸入缺報|
|external_world_shift|訓練仍為上述機率，外部五檔改為5%／15%／35%／45%|
|unseen_external_worlds|固定十檔只見`r=0/0.5`各50%；外部五檔只見`r=1/1.5`各50%|

外部五檔為1216、2303、2327、2345、2357，皆不屬固定十檔訓練宇宙。每個情境／種子是一個獨立實驗；每個候選在該實驗內只有一組跨股、跨混合窗口的權重，**不是六個壓力情境共用一組權重**。外部觀測不進入擬合、補值、校準或選模。

## 新候選與匹配比較

原四候選及其預設集合保持不變。研究明確選用第五個`history_state_hist`：使用原有hist分類器，將累積深度改成相對總深度，並加入已觀測的不平衡與20／100秒價格變化交互項。只保留28個可觀測輸入及4個交互項，逐欄取12位小數以固定數量單位變換的數值穩定性；不使用股票代碼、隱藏狀態、外部訓練資料、在線更新或真實未來答案。

這是可觀測特徵的共享非線性分類器，沒有實作狀態標籤路由或複製其他論文的模型。其特徵介面可接[本地標準委託簿資料框](INTRADAY_BOOK_INPUTS.md)，但本輪仍是理想化5毫秒已知時間的合成過程；本地資料框的一秒運算緩衝、實際發報及行情來源尚未以這輪模擬驗證。

每個候選仍只依固定十檔校準期的最低單檔準確率、整體準確率、宣告順序選模。純強情境訓練的固定`history_logistic`只作參考，不參與選模。每組保留五候選與參考的全部預測及50檔稽核，共18組、108個模型稽核。另以相同校準資料重算原四候選選模，避免把增加候選數的變化直接當成新特徵增益。

```bash
LOKY_MAX_CPU_COUNT=1 .venv/bin/python -m twquant direction-queue-study --config configs/intraday_queue_heterogeneous.json --membership artifacts/current-membership/20261107/membership.json --out artifacts/intraday-queue-heterogeneous-new-run
```

協定在生成資料及擬合前保存配置、程式摘要與環境版本。合成平日日曆不是交易所日曆；本輪使用宣告的完整50檔快照作範圍稽核，不聲稱其為歷史成分名單。IX0001使用獨立抽象指數點數答案及無委託簿的先驗回退，不能交易，也不能用ETF委託簿替代。

## 結果及解讀

18組、108個模型稽核已全部獨立重算。下表是三個種子的範圍，全部為未校準合成過程，預測與答案覆蓋率均為100%。樣本門檻除最弱五檔外，沿用目前較嚴格的最低單檔75%及逐股方向基準優勢；因此等機率環境有兩個種子的最弱五檔達75.10%，仍因最低單檔不足而未過完整門檻。

|情境|五候選選模：最弱五檔|最低單檔|樣本通過|
|---|---:|---:|---:|
|四環境等機率|73.72%～75.10%|73.30%～74.70%|0／3|
|較有利的混合環境|86.26%～86.88%|85.70%～86.00%|3／3|
|混合環境加20%弱窗口|76.18%～77.64%|75.40%～77.00%|3／3|
|混合環境加25%共同缺報|74.62%～76.38%|74.20%～76.30%|2／3|
|外部五檔環境機率改變|64.22%～66.04%|63.00%～64.60%|0／3|
|外部五檔僅見訓練未見環境|59.84%～60.12%|57.10%～58.50%|0／3|

全部8／18組通過樣本門檻；對50檔乘18個選模實驗作Bonferroni校正的單側Clopper–Pearson下界，只有較有利混合環境的3組通過，最低單檔條件下界為81.01%～81.34%。這只計算人工過程的抽樣不確定性，沒有涵蓋未知市場機率、模型失配或實際運算延遲。

以下仍是最弱五檔的三種子範圍。「原四候選」在相同資料、同一固定十檔校準期內另行選模，沒有用測試答案選控制；「新特徵候選」是單獨報告該候選，不是額外選出較好的測試結果。

|情境|原四候選選模|新特徵候選|純強訓練固定參考|
|---|---:|---:|---:|
|四環境等機率|73.72%～75.10%|74.68%～75.10%|40.30%～45.36%|
|較有利的混合環境|86.26%～86.62%|86.04%～86.88%|53.04%～60.44%|
|加20%弱窗口|76.18%～77.86%|76.64%～77.64%|50.64%～57.14%|
|加25%共同缺報|74.62%～76.62%|74.80%～76.38%|50.82%～57.08%|
|外部環境機率改變|64.22%～65.68%|64.76%～66.04%|29.10%～32.58%|
|外部僅見未見環境|59.84%～60.16%|59.96%～60.52%|25.04%～26.12%|

新特徵候選對原`history_hist`的成對最弱五檔差為−0.42～＋0.64個百分點，沒有穩定提升，故保留為明確選用的研究候選，不取代預設集合。純強固定參考與五候選選模並非相同演算法對照；以相同`history_logistic`作匹配比較，較有利混合環境重新訓練後為85.96%～86.38%，固定純強權重為53.04%～60.44%。這支持合成訓練分布適應的作用，不能把整段差距歸給新特徵。

獨立核對確認：每個候選的全部50檔每日分母、平盤、方向基準、缺報先驗回退、模型及時鐘一致；只生成固定十檔重擬合後，校準與全部53個查詢標的機率逐筆重現。變更答案、股票代碼及隱藏診斷不改推論；新候選額外忽略未宣告的`f_book_`欄。標準相對深度介面與由合成對數深度轉換的輸出一致。混合窗口對應固定係數世界的特徵與答案完全一致；外部五檔干預不改主要擬合、校準或其餘標的機率；舊純強基線的四候選機率亦逐筆重現。

本輪證明一組共享權重可以在特定混合過程內學到超過75%的條件式設計，但對未見流動性環境的轉移仍失敗。所有係數、混合機率、90%同向市場移除事件及理想到件條件均未經臺灣市場校準；不能據此宣稱市場每日任意五檔可合理預期75%。可行性設計評估不必等待所有資料到齊，但仍需要來源支持關鍵條件。
