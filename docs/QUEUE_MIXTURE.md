# 強弱窗口混合與流動性補償

這是[有限期間隊列研究](QUEUE_SIMULATION.md)的延伸。原先每個股票／日期的窗口都採相同壓力強度，不能由其高分推論臺灣任意五檔每天都有足夠資訊。本輪保留全部50檔與每日固定10:00預測，測試強弱窗口混合，並加入流動性對訂單方向的補償；所有參數仍未以市場資料校準。

後續[混合流動性環境研究](HETEROGENEOUS_QUEUE.md)另測同一組共享權重處理多種補償係數，並保留原四候選的匹配選模比較，避免將逐情境重新訓練誤稱為跨環境部署能力。

[Lillo／Farmer原文](https://arxiv.org/abs/cond-mat/0311053)發現訂單方向有長記憶，但成交量與流動性變動會抵銷其價格可預測性；[Farmer等人的後續研究](https://arxiv.org/abs/physics/0602015)亦說明，較多買方主動交易可能同時伴隨買方可用流動性增加。這些來源支持測試補償機制，**不提供本模型強窗口比例、90%同向訂單或75%方向準確率的數值依據**。

## 新的過程假設

`persistent_fraction`是各股票在每天10:00那個100秒歷史加30秒未來窗口，採強壓力的機率；不是整天的市場狀態占比。背景強度為`background_flow_imbalance`，預設0.1；強度仍為0.8，方向每秒翻轉率0.002。兩種窗口都留在資料與分母，沒有挑訊號或高信心日發報。

窗口狀態在已知歷史開始前以獨立亂數決定；未來沿用同一強度，但後續訂單仍由獨立未來亂數生成。`diagnostic_persistent_regime`僅供事後合成診斷，不能進入特徵、推論或選模。模型仍只能讀取`f_book_`的已知隊列／價格歷史摘要。

`external_persistent_fractions`可事先指定外部股票的強窗口機率，禁止覆寫固定十檔。這是轉移壓力測試，不把外部股票加入權重擬合、補值或校準。預設舊情境的強窗口比例為1，流動性補償為0，原過程的數值行為應保持一致。

`liquidity_response`是補償係數。模擬流動性提供者只使用已經發生的市場訂單方向，形成`EMA_new=0.95×EMA_old+0.05×sign`，其他事件維持原EMA。隊列重設時，買側深度乘`exp(-response×EMA)`、賣側乘`exp(response×EMA)`，向上取整且至少一單位。它不讀取未來或隱藏壓力狀態；此具體公式是本專案的反事實機制，**不是論文估計式或臺灣市場校準值**。

## 相同條件比較

四候選仍為共享先驗、即時不平衡logistic、歷史路徑logistic與hist。各情境重新用固定十檔600個訓練日期擬合、200日期校準選模，再以1000個日期完整測試。

另加一個只用強情境訓練的`history_logistic`參考模型，對同一混合測試表發報。它不是第五個選模候選，不會看外部股票或測試答案來決定是否使用；它用來區分訓練分布調整與單純更換測試窗口比例的影響。每組都保留四候選及這個參考的成績。

`configs/intraday_queue_mixture.json`先固定三個種子、30秒期間及十二情境，共36組：強窗口比例0／0.25／0.5／0.6／0.7／0.8／1；0.8加25%共同缺報；0.8但五個外部標的降至0.4；以及全強窗口加0.5／1／1.5流動性補償。沒有依結果挑較有利係數或種子。

```bash
LOKY_MAX_CPU_COUNT=1 .venv/bin/python -m twquant direction-queue-study --config configs/intraday_queue_mixture.json --membership artifacts/current-membership/20261107/membership.json --out artifacts/intraday-queue-mixture-new-run
```

協定在模擬及擬合前保存程式摘要、完整參數、Python與套件版本。合成平日日曆、理想化到件、固定一跳價差及重設規則仍沿用原研究限制，不能宣稱為真實歷史逐筆行情。

## 條件需求反推

對同一固定參考模型，令`a_s/a_b`為強／背景過程的完整分母準確率，`f_s/f_b`為同一共享先驗在兩種過程的準確率，`q`為訊號可用率、`g`為強窗口機率。已知答案情境的條件期望為：

`A(g,q) = g×[q×a_s+(1-q)×f_s] + (1-g)×[q×a_b+(1-q)×f_b]`

平盤仍不給二元漲跌得分，所以回退不預設等於0.5。各項從相同種子、同一參考模型的強／背景潛在結果估算，逐股解出達75%需要的`g`；取全50檔最大值以維持最低單檔與任意五檔標準。

這是固定模型的條件需求，不是重新訓練模型在混合情境的成績，也不是市場強窗口出現頻率的估計。重新訓練的36組比較另行稽核；即使其樣本通過，仍不能由此推論未取得資料的真實訊號強度、流動性反應或轉移能力。

樣本驗收還要求最低單檔75%，不只最弱五檔平均。全部12／36組通過；以50檔乘36組校正的單側Clopper–Pearson條件下界，9組仍通過。70%強窗口雖三種子點估均通過，下界沒有通過；不能把門檻附近的模擬樣本當成有充分餘裕的設計。

固定參考模型的逐股反推：無輸入缺報時，全50檔至少需要約61.71%～63.23%的強窗口機率；25%缺報時提高為80.56%～81.73%。這些是依成對潛在結果得到的Monte Carlo點需求，沒有含真實參數不確定性。模擬缺報與窗口狀態獨立；真實停牌、延誤若與行情相關，不能直接使用此分解。

新舊純強基線三種子、四候選的校準與全部53標的機率逐筆相同；每個混合窗口的固定參考機率及答案也與指定強／弱潛在結果逐筆一致。另已重擬合只生成固定十檔的70%案例，全部候選與固定參考機率均完全重現。外部五檔頻率干預不改主要模型、校準或其餘股票機率。

流動性補償顯著改變輸入與價格的關係；重新訓練能修正部分分布變化，但較強補償下仍未達標。固定十檔訓練的共享分類器可在部分相同情境下跨股運用，跨情境部署仍需驗證；不能直接部署純強模型或把某一有利補償係數當成市場事實。

在0.5補償下，以相同`history_logistic`演算法作匹配比較，新情境訓練的最弱五檔89.92%～90.44%，原純強訓練權重則為21.84%～42.86%。每組權重在測試期間固定，沒有線上更新或利用隱藏窗口狀態切換權重；這是合成分布變化下的比較，不能當成市場增益。

本輪提供了**不必每天都是強訊號的條件式75%模擬方案**，同時指出所需頻率、到件與流動性假設。尚無一手證據支持臺灣全部50檔每天10:00符合這些條件，因此市場75%的合理設計預期仍未建立；評估此限制不需等待所有供應商資料齊備。
