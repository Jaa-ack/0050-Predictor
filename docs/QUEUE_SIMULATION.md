# 有限期間隊列過程研究

這個離線比較檢查：只從固定十檔的已知歷史學習，能否在指定的人造買賣壓力下，對全部50檔每天完整預測原始端點方向。**生成參數沒有以臺灣行情校準，合成通過不能直接支持市場75%預期**。本研究也不開封既有真實日線保留期。

[Queue-reactive原論文](https://arxiv.org/html/1312.0563)將隊列視為狀態相關的排隊過程，並指出單靠機械波動不足以描述外生資訊。這裡借用耗盡與重設的研究思路，使用可檢查的簡化離散模型，並非原論文連續時間模型、估計率或交易成本實驗的重現。

## 過程與明確假設

每檔股票、每個合成日期有100秒已知歷史。每秒固定一個事件：65%機率從最佳隊列移除、15%撤銷某一深度、20%在某一深度新增；數量為1～4單位。兩側各五層，重設數量為`5～10+4×深度索引`。最佳買／賣隊列耗盡使中價下／上移一跳，隨後雙側重設，維持一跳價差。此固定價差及同步重設是簡化假設，不代表臺灣撮合引擎。

隱藏買賣壓力為正／負兩狀態，模型無法直接讀取；每秒以`1-exp(-flip_rate)`翻轉。市場移除的買方機率為`(1+flow_imbalance×pressure)/2`。35%的初始壓力取自同一合成市場日期狀態，其餘為獨立狀態；輸入中斷亦按市場日期共同發生。當日內其餘亂數獨立，沒有聲稱重現真實市場的全部聯動。

未來1／5／30／60秒以獨立未來亂數繼續演化，原始中價差建立答案；不以所需正確率抽取「正確／錯誤」，不把未來報酬混入特徵，也不更換為平滑三類得分。每檔、每日期及前／後期使用分離種子，增加外部股票、延長日曆或替換未來亂數，都不改變既有可見歷史。

100秒歷史只產生已知的隊列不平衡、深度及過去中價變動／波動摘要；不是完整序列神經網路。外部指數沒有委託簿輸入，使用共享先驗；其合成答案是獨立的抽象指數點數步行，不能當成IX0001真實行情。

## 訓練與選模

四控制為`prior`、`snapshot_logistic`、`history_logistic`、`history_hist`。全部補值、轉換與權重只從固定十檔成熟訓練列建立；目標訓練保留上／平／下三類，發報時將上、下機率重新正規化後以共同0.5門檻給二元答案。平盤仍不給盤中漲跌主指標得分。

預設600個合成訓練日期、200校準日期、1000測試日期。候選以固定十檔校準期最低單檔準確率、平均準確率、宣告順序依序選擇。沒有用任何外部股票挑候選，也沒有把校準列加入最後重擬合。所有控制的測試機率與成績均保留；最終模型同權重、同門檻套用全部50檔及延伸標的。

輸入中斷或指數查詢仍發共享訓練先驗，不棄答；其到件上界改為已知的選模時間。完整資料情境的5毫秒合成到件與零計算延遲是理想化假設，尚未量測現實延遲。

輸出目錄必須不存在，`protocol.json`在生成／擬合前保存程式摘要、設定、名單來源、日期角色及所有假設。每組保留四候選校準分數、訓練摘要、完整50檔稽核及全部標的預測；程式在結束時重核程式摘要。合成日曆只是自2020-01-02起的週一至週五，不是已核實臺灣交易日；沒有資料到件、官方休市或市場實績的主張。

這個命令不讀取伺服器憑證、不連線供應商、不載入外部權重、不新增訂閱、不部署或交易。`empirical_target_met`、`real_world_target_verified`及`unconditional_75_expectation_supported`維持`false`。

## 已完成的條件比較

60組比較及240個控制模型稽核均已完成並獨立重算。下表只整理事先指定的主要30秒期間；數值為三種子範圍，包含每個日期、平盤及缺輸入時的先驗答案，**全部為未校準合成資料**。

|情境|最低單檔|最弱五檔平均|三種子樣本驗收通過數|
|---|---:|---:|---:|
|neutral_flow|40.70%～44.40%|41.06%～44.78%|0／3|
|persistent_flow|93.20%～93.80%|93.90%～94.06%|3／3|
|pressure_reversals|55.70%～56.20%|56.10%～56.76%|0／3|
|market_feed_outage|80.00%～82.50%|80.48%～82.70%|3／3|
|weak_external_transfer|41.30%～45.10%|45.90%～47.26%|0／3|

本次選模結果的1／5秒均未通過；60秒持續壓力情境的最弱五檔為90.72%～91.48%，缺報情境78.04%～80.46%，弱股情境47.46%～50.00%。全部期間合計12／60組通過合成樣本門檻。以50檔乘60組作Bonferroni校正的單側Clopper–Pearson條件下界，8組仍高於75%；它只描述這個人造過程的取樣變動，不能當成市場未來準確率的信賴下界。

強壓力情境的0.8參數，相當於指定隱藏狀態下90%市場移除朝同方向，且翻轉率很低。這種可見歷史的高資訊量足以讓共享歷史logistic學會預測，但並無證據顯示臺灣全部50檔、每天10:00都有這個強度。僅將五個外部標的強度改弱，就能保留原十檔全部訓練摘要、校準分數與選模結果，卻使最弱五檔明顯退步。這不是將平均高分解讀成任意五檔可轉移的依據。

已另以只生成固定十檔的資料重擬合指定案例，四控制的校準及全部53標的機率逐筆一致；12組外部強度干預的主要模型／分數亦完全一致。最後補強成熟性護欄，要求端點先於擬合且到件不早於端點；實驗原數值與程式快照保留，分類器本體未改，修正後指定案例重播機率仍逐筆相同。沒有將後續驗證修正重標為原實驗來源。

這一輪已證明一個實際學習模型可在明確條件下達到模擬75%，也量化了條件失效時的弱股落差；**可信的市場75%設計預期仍未建立**。下一步應反推持續壓力的必要出現頻率及轉移範圍，不能單靠增加網路層數或挑最高種子補足這項證據。
