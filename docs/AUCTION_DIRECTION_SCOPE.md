# 集合競價方向的目標區別

本輪另核對集合競價研究，尚未取得可支持臺灣任意五檔、每日完整75%方向準確率的一手數據。試撮價的資訊性與方向準確率不是同一指標。

|目標|已知資訊與待預測部分|與現有驗收的關係|
|---|---|---|
|目前中價到固定未來端點的變動|目前價格已知，整段後續價差未知|現行盤中研究；平盤保留且不給二元漲跌得分|
|正式開盤相對前收的方向|前收已知，當時試撮價是候選訊號，正式開盤尚未發生|另一目標；不能把它的分數稱為當前價格之後的新變動準確率|
|正式價格相對當時試撮價的修正方向|試撮價已知，尚未知的訂單／撤單改變最終撮合|不能用試撮接近正式價格，推論修正方向也可達75%|

[Challet／Gourianov原文](https://arxiv.org/html/1802.01921)研究美股集合競價，指出試撮價與不平衡具有均值回歸、訂單新增或撤銷對最終價的影響不同，且臨近撮合的更新密度會提高。研究的市場規則與資料頻率也限制轉移；沒有提供本系統完整每日二類方向的75%成績。

[證交所交易制度](https://wwwc.twse.com.tw/en/products/system/trading.html)區分連續交易、開收盤試撮及暫緩撮合；試撮揭示不等於已成交價格，開盤也可能延後。任何後續開盤研究都需保留延後、缺報與無法確認答案的日期，並固定宣告參考價格、截止時間及平盤定義。

「正式開盤相對前收」目前不屬於已採納的驗收目標。現行研究仍採端點變動，沒有替換標籤、宣稱集合競價達標或啟用新行情擷取。

在此期間完成的[本機委託簿接口](INTRADAY_BOOK_INPUTS.md)只接受正常連續交易快照，試撮不能悄悄混入目前的端點方向模型。若之後採納集合競價目標，需要獨立資料契約及結果，不能更名重用既有成績。
