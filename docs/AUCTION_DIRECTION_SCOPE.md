# 08:59 開盤方向研究

2026-11-20 將**正式開盤價是否高於上一交易日收盤價**列為獨立的 75% 研究任務。每天臺北時間 08:59:00 對所有宣告成分股發出二元預測，平盤歸為「未高於」。答案使用原始價格，除權息等因素反映在實際價差中。停牌、無有效成交、逾時或行情缺失保留原分母。延後開盤使用當日公布的正式開盤價。預測端只能使用截止前已收到的資料。

| 目標 | 已知資訊與待預測部分 |
|---|---|
| 正式開盤相對前收 | 前收已知，試撮價是候選訊號，正式開盤仍待成交 |
| 正式開盤相對當時試撮價的修正 | 試撮價已知，待預測後續訂單與撤單造成的修正 |
| 盤中 10:00 後 60／300 秒首次成交變價 | 盤中的成交與委託簿為輸入，各期限以凍結試驗原規則計分 |

證交所於開盤前揭露試撮資訊，並有暫緩開盤機制。試撮行情和一般逐筆成交各有獨立格式。歷史日線提供開盤標籤，帶原始收件時間的試撮才能驗證靠近截止點的訊號品質。 [證交所交易制度](https://www.twse.com.tw/zh/products/system/trading.html)

## 固定協定與實作

- 價量、同儕、美元匯率與波動、法人與融資券、美股／ADR、臺指／電子／金融夜盤沿用 08:30 盤前快照。夜盤按同月契約與交易量歸屬日對齊。08:59 的試撮、早盤期貨、匯率及新聞從獨立帶時鐘的特徵介面接入。 [期交所盤後交易歸屬規則](https://www.taifex.com.tw/cht/4/aHIntroduction)
- 固定十檔是唯一訓練、校準與選模資料。逐折使用較早且已成熟的答案擬合，再以後一段 126 日校準樣本的最弱五檔、整體準確率、Brier 依序選模。其後對完整 50 檔及 0050、1216、2002、2412、IX0001 使用同一模型與 0.5 門檻。IX0001 只以指數價格計分。
- 候選包含訓練頻率、夜盤方向、價量邏輯斯迴歸、跨來源邏輯斯迴歸及提升樹。另做來源移除比較。加入新聞、試撮或早盤因子前，個別因子需在該折已成熟訓練期中有至少 63 個市場日的觀測。資料稀疏時保留缺值，完整缺訊號時以固定十檔的訓練頻率發出答案。
- 75% 驗收沿用任意五檔的完整日格，同時要求逐檔達標、方向優於固定類別基準及具備完整及時預測和答案。以日期為單位保留成對分數與區塊抽樣資訊。未來驗收應先凍結模型、截止與交易日曆，再累積獨立影子預測。

## 試撮週後的模型比較

11/25 預先定義以下三個候選。在 11/27 原定週報完成後，以 11/23–26 為訓練期、11/27 的固定 50 檔為同日留出日。沿用 08:59 截止、原始昨收、正式開盤答案及缺答計錯規則。訓練只使用固定十檔及在留出日截止前已成熟的答案。

| 方案 | 配方 | 11/27 的分數來源 |
|---|---|---|
| 原試撮模型 | 保留試撮價差、試撮量與五檔不平衡的正則化邏輯斯迴歸，以及既有填補、回退和決策規則。基準程式為 `bd6ab2a` 的 `src/twquant/opening_capture.py`。 | 原定週報 `evaluation.json` 的 `validation` |
| 試撮方向 | 最後一筆合格試撮價高於昨收就預測上漲。試撮缺報則沿用週報的「未上漲」回退。 | 原定週報的 `validation_trial_rule` |
| 試撮加修正 | 短週原型只估計固定十檔共同的修正幅度。對有合格試撮和成熟開盤價的訓練列，計算 `(正式開盤價 - 試撮價) / 截止前已知昨收`，取中位數。將此值加到留出日的試撮價差，再以是否大於零判方向。試撮缺報沿用試撮方向的回退。沒有有效訓練列時，標示修正模型未擬合。 | 週報完成後，透過私人收件資料另行重播並記錄有效訓練列數 |

保留原採集與評分程式、試撮資料庫和週報。按股票配對統計每個方案救回幾個試撮錯誤、又改錯幾個原本正確的方向，並列出 50 檔命中數、兩類召回率、缺件、回退及單日最弱五檔。11/27 的標籤只用於驗證，短週原型的配方在看到成績前固定。既有的長歷史盤前模型及 10:00 紙上試驗以各自原任務計分。

| 留出日比較結果 | 下一輪優化方向 |
|---|---|
| 修正方案命中數最高且沒有並列，上漲與未上漲召回率均未低於直接試撮 | 優先發展試撮修正，逐步測量尾段價量與五檔的增益。 |
| 直接試撮命中數最高（含並列），當天兩類答案皆有樣本 | 以試撮方向為基準，優先查缺報、過舊報價與接近昨收時的翻向。 |
| 原模型獨自領先，且兩類召回率均未低於試撮方向 | 優先復驗原模型的試撮量和五檔增益，並保留試撮方向與修正方案作對照。 |
| 其他結果，例如兩個模型並列領先、領先方案犧牲一類召回，或該日缺少一類答案 | 保留原模型和試撮基準，先累積多方向交易日再決定擴大何種模型。 |

短週結果用於排序研究方向。後續需在多個新交易日以相同模型和完整日格評估，報告最弱五檔、最低單檔和相對試撮基準的成對差異，再判斷是否達到任意五檔的 75% 目標。

## 多來源權重與因子優先順序

`opening-gap --source-fusion` 將同一折訓練期的前 75% 交易日用於估計各來源的方向分數，用後 25% 學習加權及缺報指示。來源子模型只使用在後段起始決策前已成熟的答案。外層沿用獨立的固定十檔校準期與完整成分股留出期。分來源加權與完整線性、提升樹及移除單組來源的模型在相同日期比較。

以 2026-05-05 至 11-05 的既有 126 日歷史切割重跑，線性、分來源加權、提升樹的整體命中率分別為 71.00%、70.87%、70.29%，最弱五檔分別為 54.29%、54.44%、57.30%。提升樹依固定十檔校準規則入選。夜盤上漲且 SPY 上漲時 47 日中 70.89% 的標的開高。兩者均未上漲時 44 日中 29.34% 開高。這些是既有歷史期的描述統計。該矩陣只有歷史價量、美股、夜盤、籌碼與總經的覆蓋。

| 因子 | 要驗證的條件與方向 |
|---|---|
| 個股價量、同儕、五檔與試撮 | 同向且試撮價差穩定時檢查延續性。接近昨收、尾段翻向、委託簿偏薄時檢查反轉及資料缺口。 |
| 美股／ADR、區域股市、早盤與夜盤期貨 | 按個股產業曝險測試同向與衝突情境。分開核對本地交易日、契約與來源可用時刻。 |
| 產業、籌碼、匯率與總經 | 依產業對利率、原物料、匯率的曝險測試交互作用。籌碼與成交量同時保留延續和反轉候選。 |
| 財報、法說會與重大訊息 | 對照當時已知預期及展望，分開衡量財報驚喜、上修與下修。以日別明確的公司行動參考價處理原始開盤價的機械變動。 [公開資訊觀測站](https://mops.twse.com.tw/) [除權息參考價](https://wwwc.twse.com.tw/zh/announcement/ex-right/twt49u.html) |
| 新聞 | 依事件與公司去重，從官方公告、新事件及獨立媒體報導分別建特徵，保留首次到達和修訂時間。 |

先採一組加入與移除的同日比較，再測可解釋的交互作用。依全覆蓋、方向優勢、最低單檔及整體準確率決定保留哪些來源。將新取得的現行快照保存真實收件時間，後續只在可驗證的時間範圍加入訓練。

## 逐檔門檻與同日因子試驗（2026-11-27 盤前）
