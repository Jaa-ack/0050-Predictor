# 深度、活動率與成交價首次變動

2026-11-14完成的兩組離線研究，檢查[方向持續研究](PERSISTENT_FIRST_CHANGE.md)留下的初始深度及事件率假設。這裡仍是每天10:00預測60秒內第一次成交價變動，包含價差反彈；所有50檔每日必答，逾時、未知與缺報均不給分。使用者另接受的300秒目標見[獨立研究](FIVE_MINUTE_FIRST_CHANGE.md)，沒有改寫60秒結果。

**結論：共享價差反彈規則在部分非中立、較深且足夠活躍的人工市場仍超過75%；薄深度或低活動率可以使它失敗。** 深度參數與時鐘轉移均已實作及核對，尚非現今臺灣50檔的校準分布，也不能據此保證任意五檔的市場準確率。設計評估不必等待實績，但市場預期仍須有參數依據。

## 深度研究

[設定](../configs/depth_persistent_first_change.json)事先固定十二條件、種子401／443／487、600訓練／200校準／2000測試平日、四候選，共36組與144個候選稽核。平日為合成日期，沒有宣稱符合臺灣歷史休市日。使用凍結50檔成分清單；唯一擬合、校準、選模與同儕來源為固定十檔，外部股票只查詢自己的已知輸入。IX0001沒有成交價或委託簿，保留先驗回答與未知答案。

全部情境的原始事件率為每秒100筆，資料截止至發報延遲1毫秒。初始深度是過去100筆委託之前各價位的數量範圍，並非10:00最佳報價保證下限；之後不重設或虛構補量。普通單量為1／2／3／4，比例60%／20%／10%／10%。方向強度g相對隱藏壓力定義，g=0.5／0.8對應75%／90%委託沿壓力方向，並非預測正確率或相鄰成交同向機率。隱藏狀態不供模型讀取。

## 同一模型的時鐘轉移

新增[`matching_clock_scale`](../src/twquant/matching_clock_scale.py)，將所有事件率除以s、資料延遲乘以s，保留亂數事件順序、可觀測事件歷史及真正發報錨點，再按原60秒截止判斷逾時。這是同一路徑的配對重表達，不是新增獨立市場樣本。過去窗口仍為100事件，因此變慢後覆蓋較長實際時間；未假設固定秒數窗口的特徵也相同。

[設定](../configs/depth_clock_transfer.json)在新測試前指定s=1／50／100／200／1000。一般股票分別對應100／2／1／0.5／0.1事件每秒，以及1毫秒／50毫秒／100毫秒／200毫秒／1秒延遲。外部快股仍保持十倍事件率。速率與延遲同時改變，兩者乘積固定，不能據此宣稱任意獨立延遲均有相同成績。

每種子只在第一個預先指定情境thin_p50的固定十檔600訓練日期擬合一次spread_bounce，三個模型直接查詢全部十二條件與五種速度；沒有在新環境或外部股票重新校準或選模。模型使用已知末筆成交在買賣報價之間的位置；缺輸入仍回答共享先驗。

共180組、每組50×2000個驗收回答，全部完整發報。96組通過樣本75%，90組通過共同條件下界；按速度依次為30／30／27／9／0組與30／30／24／6／0組。下界家族為50×180=9000，單側Clopper–Pearson總錯誤率5%；每組取最低五個逐股下界平均，涵蓋全部2,118,760種五檔組合。這是給定人工模型的抽樣界限，未計入市場模型錯置。

例如deep_p50在每秒1事件時逾時約7.10%～7.24%；每秒0.1事件時約72.31%～72.51%，全部計錯。此撮合過程若沒有激進委託便無法成交變價，故母體準確率必要上限為1−exp(−r×m×T)，r為總事件率、m為激進比例。r=0.1、m=0.15、T=60時上限59.34%，更換分類器不能消除此人工過程的等待限制；有限樣本仍有抽樣誤差。

獨立驗證重新擬合三模型，核對全部180組完整格、逐股分數、9000比較下界、陣列與DataFrame全部機率、未知／逾時轉換及錨點；另直接重播1152條撮合路徑，涵蓋每情境、種子、兩速度及主要／外部股票。時間誤差不超過s+1奈秒。逐股正確次數隨速度降低只會不增。結果未將無成交目標的IX0001記為0%假準確率，而是明列未知。

## 市場依據的邊界

[臺灣2021研究稿](https://acfr.aut.ac.nz/__data/assets/pdf_file/0008/578429/Ivan_TWSE_15Nov2021.pdf)表5報告改制後彙總最佳報價深度約323,480股，表7平均成交量約3,360股。兩個彙總平均不能直接形成逐股深度／成交量分布，更不能推導所有股票尾端或目前10:00的條件；表1與表7的改制前成交量統計亦不可混用。50～100單位初始深度是明列的量級情境，並非已估出的現今臺灣參數。

[證交所共置服務問答](https://www.twse.com.tw/en/products/colo/qa.html)列明申請資格及NTP，並表示目前不提供PTP；它未承諾本專案端到端1毫秒或100毫秒新鮮度。程式計算時間亦不包含行情收件、特徵準備與發報。未申請服務、付費、啟用行情排程或下單。

條件式設計候選已具可執行版本，反例也有具體參數與完整分母。仍缺少的是當前50檔在固定時點的深度、活動率、方向持續性與接收延遲的聯合分布依據；合成高分與官方服務存在本身都不能補成這個依據。
