# 成交價首次變動的方向持續壓力研究

後續已完成[深度與時鐘轉移研究](DEPTH_CLOCK_FIRST_CHANGE.md)，以新的凍結條件檢查初始深度、較慢活動率及完整逾時。下列原始情境、來源版本與失敗結果保留。

本輪檢查[毫秒延遲研究](OPERATIONAL_FIRST_CHANGE.md)尚未涵蓋的方向持續性。每天10:00對全部50檔回答，評分發報後60秒內第一個不同成交價格；逾時、未知、缺報與弱股票全部保留。最低五檔平均對應任意五檔的要求，最低單檔另列。

唯一訓練、補值、校準與選模來源仍為固定十檔。其餘成分股及0050、1216、2002、2412使用同一共享模型查詢；IX0001保留先驗回答與未知成交答案，不建立指數委託簿。固定反彈策略在擬合前指定為精簡設計候選，並完整比較共享先驗、logistic與hist；其他模型的分數不套用反彈策略的陣列推論時間。

## 方向參數的意思

強度g是相對隱藏壓力的買賣偏向。給定壓力方向，委託沿該方向的機率為(1+g)/2，因此0.2／0.5／0.8對應60%／75%／90%；這不是預測準確率，也不是相鄰兩筆成交同向的比例。

每事件隱藏壓力翻轉機率為1−exp(−h)。在對稱穩態、固定強度及獨立委託亂數下，相隔k個事件的委託方向乘積期望為g²[2exp(−h)−1]^k。這描述全部輸入委託的買賣方向，不能直接當成個別成交片段的相關性。

|強度|h|沿隱藏方向機率|相鄰委託同向機率|隱藏壓力平均持續事件數|
|---|---:|---:|---:|---:|
|0|0.002|50%|50%|500.500|
|0.2|0.002|60%|51.992%|500.500|
|0.5|0.002|75%|62.450%|500.500|
|0.8|0.002|90%|81.872%|500.500|
|0.5|0.05|75%|61.281%|20.504|

以現有委託產生程式另核對五組、每組4096路徑各512事件，共10485760個方向；延遲1／5／20／100事件的乘積期望與公式最大差異小於0.009。這只核對參數意義；完整成交價格與時間另由獨立字典／標量路徑驗證。隱藏壓力、強度與未來錨點不供分類器使用。

## 文獻依據與限制

[Lillo、Mike與Farmer的研究](https://arxiv.org/abs/cond-mat/0412708)說明，大單逐步拆分與重尾母單長度可能形成買賣方向的長期相關。[Sato與Kanazawa的研究](https://arxiv.org/abs/2301.13505)以東京市場九年以上的交易者資料檢驗該機制。它們支持檢查方向持續性，沒有提供臺灣目前50檔的本輪參數或75%準確率。

[臺灣委託選擇研究](https://www.sciencedirect.com/science/article/pii/S1062940822000912)的公開預覽亦描述短期委託序列相關；本輪未確認其樣本年份，沒有當作改制後或現今臺灣的數值校準。直接內容取得回應403，未繞過存取限制。

本輪使用兩狀態、有限記憶的方向近似，衰減為指數形式；並非重尾母單、交易者ID或完整LMF模型的複製。快速翻轉只改變委託方向，不模擬消息造成的價格跳躍。全部事件比例、方向強度、深度與固定時點分布仍為明示人工條件，條件抽樣界限不涵蓋未知市場分布差異。

本輪僅進行離線研究與公開文獻查核，沒有連接券商、訂閱來源、啟用真實排程或交易。
