# 模擬過程的資訊上限

[混合流動性研究](HETEROGENEOUS_QUEUE.md)在未見外部環境下失敗。這份診斷用來區分「模型沒有學好」與「所選人工過程的未來仍有太多隨機性」，避免把增加架構複雜度當成必然可達75%的理由。**診斷不產生可部署預測，也不列入候選選模。**

## 給予估計器的額外資訊

令`S`包含完整五檔買賣隊列、當前隱藏壓力、強弱係數、流動性係數及訂單EMA，並假定已知人工轉移規則。這比實際預測器的觀測摘要更有資訊；獨立未來事件在給定`S`後依原隊列過程抽樣。對平盤不給漲跌得分的定義，知道`S`的最佳平均正確率為：

`A* = E_S[max{P(Δ>0 | S), P(Δ<0 | S)}]`

對上漲／非上漲診斷，第二項改成`P(Δ≤0 | S)`。前者的平盤機率不會自動轉成正確答案；後者可能因大量平盤而很高，不能據此宣稱方向優勢或改變目前驗收定義。

這是[Bayes最優分類](https://gradml.mit.edu/supervised/classification_fundamentals/)在本專案計分規則下的推導。給定完整當前狀態仍只知道未來機率，不會知道哪條未來路徑真正發生。實際特徵能達到的最優值不會高於完整狀態的最優值；上限高於75%只表示沒有被這個診斷排除，並不證明存在可用的75%方法。

## 獨立分支與偏誤控制

每個股票／日期保留100秒過去生成的同一當前狀態，另外抽取64條未來路徑。原實驗答案使用`phase2`，這次只使用獨立`phase3`；不讀原測試答案，也不把隱藏狀態或分支結果提供給共享模型。改變分支種子不改當前狀態；擴充日期、標的、分支數或變更運算分塊，也不改既有分支。所有期間共用相同未來路徑的對應端點。

每個日期的分支頻率最大值`Z=max(頻率_up,頻率_down)`因Jensen不等式而向上偏，故只能作上限方向的估計，不能稱為模型準確率。另以前32條分支選漲／跌方向，在後32條獨立分支評分，得到`W`。其期望不超過完整狀態的最優值，因此可提供下界方向的估計；這個政策仍擁有隱藏狀態與已知生成規則，不能部署。

令`D`為每檔獨立生成的日期數、`F`為全部股票×情境×種子×期間比較數，兩種計分乘上下兩個界限共四個項目，使用：

`ε = sqrt(log(4F/α)/(2D))`

`lower = max(0, mean(W)−ε)`；`upper = min(1, mean(Z)+ε)`。

這是由[Hoeffding獨立有界變數不等式](https://doi.org/10.1080/01621459.1963.10500830)與聯集界推導的人工過程母體平均界限；沒有將64條分支當成64個獨立市場日，亦不要求股票、期間或情境之間獨立。它要求各日期按宣告的隨機規則獨立生成，種子僅作重現，不能作預測訊號。有限分支的向上偏誤使上界偏保守；未以市場校準的轉移律本身仍是更大的限制。

完整50檔都保留於每個日期／期間，不依信心、平盤或輸入可用性篩選。即使模擬缺報，完整狀態診斷仍比實際回退模型有利。各股上界同時成立時，取最小五個上界的平均仍是最弱五檔真值的上界；它低於75%才能在宣告的人工過程下排除任意五檔平均75%。最低單檔門檻另行報告，不與五檔平均混用。

另對前輪已固定的等機率、有利混合、外部機率改變及外部未見環境，使用同一股票各固定係數界限的加權和。完整狀態包含係數，故人工混合過程的最優值等於各條件最優值的機率加權；前輪係數是在歷史開始前獨立抽取，符合此分解。這些推導沿用已同時成立的組件界限，不另外產生預測或消耗新的錯誤機率配置；沒有依結果調整原混合機率。弱窗口與補償的交叉組合未全數診斷，不對其套用此加權。

## 固定實驗

`configs/intraday_queue_ceiling.json`事先固定：完整50檔、三個種子、1000個狀態日期、每日期64分支、1／5／30／60秒、五個過程。日期從原合成平日日曆偏移800日起算，對應先前研究的測試日期；仍不是交易所歷史日曆。五個過程為持續強壓力、流動性補償0.5／1／1.5，以及強度0.1的背景訂單流，共15組、60個期間面板。`F=3000`，總錯誤機率配置`α=0.05`。

```bash
LOKY_MAX_CPU_COUNT=1 .venv/bin/python -m twquant direction-queue-ceiling --config configs/intraday_queue_ceiling.json --membership artifacts/current-membership/20261107/membership.json --out artifacts/intraday-queue-ceiling-new-run
```

協定在抽樣前保存配置、來源程式與環境摘要。輸出是分支計數，沒有`probability_up`、`actual_return`或`model_version`預測欄，不會進入模型工廠、預測稽核或正式模型門檻。IX0001沒有委託簿，明確拒絕送入此診斷；既有共享模型的指數轉移查詢維持另行處理。沒有擬合、外部訓練、供應商連線或實際下單。

## 結果

15組、60個期間面板及300萬列條件計數已完成並獨立重算。下表為三種子的**最弱五檔完整狀態最優值上界，並非模型準確率**。每股每期間均保留1000個狀態日期；各界限的日期層半徑為7.8703個百分點，已配置全部比較。

|人工過程|1秒上界|5秒上界|30秒上界|60秒上界|
|---|---:|---:|---:|---:|
|持續強壓力|23.96%～24.39%|80.87%～80.97%|100%|100%|
|補償0.5|19.54%～19.55%|62.22%～62.74%|100%|100%|
|補償1|17.15%～17.33%|48.88%～49.17%|83.69%～83.98%|90.53%～90.57%|
|補償1.5|16.12%～16.40%|41.84%～42.48%|59.51%～59.75%|61.17%～61.30%|
|背景強度0.1|19.35%～19.59%|53.10%～53.28%|62.25%～62.38%|68.52%～68.57%|

因此，在宣告的人工隨機規則及錯誤機率配置下，補償1.5與背景過程的全部50檔、全部四個期間均可排除75%；補償0.5／1在5秒亦可排除。知道隱藏狀態仍不足以克服這些情境的未來不確定性，換分類器不能解決該過程內的75%缺口。反之，表中100%是保守界限截斷為1，並非完美預測，也不提供市場達標證據。

對前輪既定混合機率作加權推導，得到下列最弱五檔上界；外部目標仍沒有進入訓練或校準：

|既定混合過程|30秒上界|60秒上界|
|---|---:|---:|
|四環境等機率|85.84%～85.96%|87.96%～88.00%|
|較有利混合|95.54%～95.59%|96.65%～96.66%|
|外部五檔機率改變|76.42%～76.75%|79.50%～79.69%|
|外部五檔僅見訓練未見環境|72.04%～72.44%|76.20%～76.42%|

外部未見環境的30秒上界已低於75%，說明前輪該案例的失敗不只是訓練分布或特徵不足。60秒仍未被這個較寬的界限排除，不能把76%上界當成已找到76%模型。補償1的最弱五檔分支頻率最大值點估在30秒約75.82%～76.11%，60秒約82.66%～82.70%；這些仍向上偏且擁有隱藏資訊，只能提示後續可研究的空間。

平盤定義的影響同樣明顯：1秒的逐股平盤分支平均點估為80.23%～91.76%；若改用上漲／非上漲，永遠回答非上漲的基準點估已達89.48%～96.26%。這是相同人工分支的描述統計，並非額外校正的信賴界限或有方向優勢的模型；不得用來替代目前平盤不給分的目標。

兩檔四日期的獨立逐事件純量參考，完整重現當前狀態雜湊及64分支各期間計數；運算分塊與擴充分支測試保持相同路徑。抽取共用歷史前後的六組原始資料框逐列一致，三個已封存固定係數測試面板的原答案亦逐筆相同；完整Python547項、前端10項及秘密資料稽核通過。

本輪提供了排除部分不可能假設的證據，沒有建立真實市場75%的合理設計預期，也沒有要求先取得全部供應商資料才能作出這個可行性判斷。上界不會使`target_feasibility_established`或市場達標旗標成真。
