90秒是迴圈排程預算，不能中斷已在執行的核心I/O；最外層仍有停止與強制終止界限。這不是零遺失保證。VM斷電、SIGKILL、佇列溢位、磁碟不足或持續I/O卡住時，尚在RAM的資料仍可能遺失；不完整回執亦可能只留下缺失告警。

`collector_closeout.json`記錄最新一次；`collector_closeouts.jsonl`保留各次停止，均為私人0600檔。`complete`只表示該次已接收訊息的處理與提交檢查通過；提前停止仍標為`stopped`，不冒稱完成整個採集窗口，也不代表交易所逐筆完整性。
