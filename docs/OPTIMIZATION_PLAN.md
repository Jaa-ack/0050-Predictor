# 可行性判斷與優化順序

這是後續實作與實驗計畫，未將建議描述成已完成的功能。當前第一階段工程可執行，完整資料證據、成本後優勢及真正逐日紀錄仍須分別驗收；API通過不直接解除模型門檻。帳號及實際研究數值只留本機報告。

## P0：讓驗收能識別無效模型

1. **補足基準。** 除現有線性模型外，同時報告固定0.5機率、只由訓練期估計的上漲比例、永遠預測上漲的方向參考及0050被動持有。增加預測上漲比例、混淆矩陣、每類召回率與balanced accuracy，防止單一方向輸出被當作擇股能力。不得用測試期比例訓練基準。
2. **機率與辨識分開診斷。** Brier／log loss與可靠度曲線一起讀，按期間與市場狀態檢查過度自信。Brier同時受校準與辨識影響，不能單靠一個分數認定校準改善。[scikit-learn官方說明](https://scikit-learn.org/stable/modules/calibration.html)
3. **評估相依與選樣。** 按交易日期／時間區塊估計成對損失差，不將同日多檔股票視為獨立市場樣本；5／20日重疊標籤須保留purge及embargo。探索性bootstrap要揭露區塊長度，不能據此宣稱保證顯著。[時間序列驗證](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-of-time-series-data)
4. **登記已檢視期間。** 保留已開封與曾用於模型選擇的日期；新設計只在開發期選擇，修改後需新的獨立未來驗證。不可對已開封日期反覆調參，再重新稱為未接觸保留期。

驗收：同一批逐筆預測可重現全部基準與方向分布；常數／單一方向模型不因表面準確率獲得優勢結論，正式門檻仍須資料與未來證據。

## P0：讓預測與可成交收益對齊

- 保留收盤至未來收盤的股價預測任務，另建與實際下單時點相符的下一開盤至持有期末報酬任務；不要直接把包含隔夜跳空的預測當成日內可得收益。
- 先在相同已選交易上拆解成本前／後表現，再依實際券商費率、稅與滑價作壓力測試。成本設為零時仍須維持原本選股，否則混入改變交易集合的效果。
- 5／20日要有逐日資產、重疊部位、資金占用及換手控制，才可比較交易績效；補部分成交、漲跌停與容量情境。

驗收：成交目標、預測標籤及評分時間明確；相同交易可重現目前淨報酬，費率調整不得成為美化結果的方法。

## P1：以消融實驗決定因子與模型

- 固定日期、股票池、成熟標籤與成本，比較價格／量、再加美股、再加FRED，最後才加入有原發布證據的財務／籌碼／新聞。不同歷史年限分開比較，不犧牲多年基準來容納短期事件。
- 針對非平穩價格水準，測試報酬、變動率、利差及相對偏離；這是候選轉換，不宣稱所有水準特徵都無效。相關特徵以群組處理，單欄重要度可能被替代訊號掩蓋。[特徵重要度限制](https://scikit-learn.org/stable/modules/permutation_importance.html#misleading-values-on-strongly-correlated-features)
- 比較擴張與固定長度訓練窗口、校準窗口及模型混合權重；僅在巢狀時間切分的開發期選擇，不在保留期選贏家。
- 增加相對0050的個股超額報酬／橫斷面排序任務，分開看市場方向與選股能力。條件分位數、分狀態區間及進階模型需以相同基準驗收。

驗收：保存每次實驗與試驗總數，結果包含Brier、MAE、區間寬度／覆蓋、Rank IC及成本後績效；增加因子或模型複雜度需要可重現增益。

## P1：資料與執行環境

- 最新及歷史前十大權重、公告／生效日期、臨時休市、公司行動與還原版本仍是必要資料；固定十檔研究不能改稱歷史0050前十大策略。
- 財報需統一金額、股數、累計／單季、TTM及金融業科目；公告／新聞保留原始與修訂版本。先從現在累積實際收件，不補造過去發布證據。
- 富邦連接必須在支援的Python／SDK環境執行。若主研究與官方SDK版本不同，須統一相容環境或建立受限制子程序橋接，只傳正規化行情與固定錯誤，不傳帳戶物件或秘密；抽測成功不等於主工作流程已完成自動橋接。

## P1：每日執行與未來實績

- 分離每日資料／預測、定期重訓與完整歷史研究，避免每日重抓多年資料與重跑所有折。重訓頻率也是策略設定，需凍結並納入程序版本。
- 增量原始行情仍需完整的還原係數版本；公司行動後重抓／重建受影響歷史，不拼接不同版本的還原價格。
- 補常駐主機、臺北時區排程、跨程序互斥、重跑冪等、缺漏回補、失敗告警與備份。20:00前、資料不齊或未核實交易日時不發出該模式預測。
- 真正及時簽發並成熟的未來紀錄才計入60日／500筆門檻；歷史重播與合成展示永久分開。
