## 資料完成程度

已實際取得2014年至今的十五標的日線（股票／ETF原始與還原、TAIEX價格指數），長期FRED與選定美股因子亦已跑完擷取及數值匯出。上市／重組較晚的標的不補造早期歷史。當前公告、集保、期貨及新聞中繼資料已可保存，但沒有藉此宣稱十年事件歷史已齊。

仍缺：

- **歷史可用時間及還原版本證據**：目前日線按20:00重建，採供應商最新向後還原；不是當年實際保存的版本。美股收盤亦按規則重建，不直接取得verified標記。
- **歷史股票池與完整日曆**：固定名單為使用者指定的主要目標，仍有事後選樣限制；另做動態前十大策略時才需歷史權重、公告／生效日期與臨時休市資料。
- **臺股基本面與籌碼版本**：財報／營收原始公布、更正、單位與科目標準化；最新集保快照不能替代過去發布版本。
- **新聞與政府事件模型**：較完整繁中新聞歷史、精確公司實體、事件／情緒標註與消融實驗；GDELT最新批次不代表全天或全年完整覆蓋。
- **夜盤及分析師預期**：歷史合約、換月、分K、日夜盤session及歷史共識快照，仍未成為可驗證的完整因子引擎。

## 模型及正式上線

工程流程可以執行，正式可行性仍須同時通過資料時點／還原證據、樣本外優勢、固定保留期及至少60個真實交易日／500筆成熟一日預測。歷史回測或今天補發的預測都不能取代未來實績。

目前只模擬下一開盤進場至當日收盤、隔夜空倉的1日策略；5／20日預測有統計評估，但尚未實作多日重疊持倉、部分成交、漲跌停排隊與容量／市場衝擊。方向正確率高不等同該策略成本後報酬通過。

尚缺市場／個股alpha分解、產業適應、正式條件分位數及SHAP；LightGBM／Qlib／FinGPT等不是安裝後就會改善結果，需按相同切分和成本做獨立增益驗證。程式碼LICENSE與供應商資料公開展示授權也仍須由維護者選定。
