# 網頁操作與版本更新

從專案根目錄啟動本機工作台：

```bash
.venv/bin/python -m twquant demo
.venv/bin/python -m twquant --root artifacts/demo serve --port 8000
```

開啟 <http://127.0.0.1:8000>。右上切換「合成研究示範」或「實際資料研究」。兩個工作區有獨立資料、模型及預測帳本；切換不會把合成資料混入真實研究。尚無行情或模型時會呈現空狀態。

| 頁面 | 操作與判讀 |
|---|---|
| 研究總覽 | 比較 Brier、區間覆蓋、資產曲線與六類啟用條件；圖例可切換曲線 |
| 個股預測 | 選擇1／5／20交易日、搜尋股票、開啟歷史價格及預測終點、因子代理／估值、匯出JSON |
| 歷史回測 | 比較各期間方向、報酬誤差及基準；查看成本、保留期與研究版本 |
| 資料來源 | 查看設定狀態、缺少的欄位名稱、來源快照與同步結果；頁面不顯示Key值 |
| 工作流程 | 執行固定六種任務、查看進度及結果；單一任務執行，畫面自動輪詢 |
| 待完成項目 | 按P0／P1／P2篩選缺口與驗收條件，連至完整文件 |

「產生影子預測」使用現有已訓練及校準模型，不會自行重訓。新增資料後先執行「校驗到期預測」，再「執行歷史研究」建立新版本及校準，最後產生新預測。原始帳本不覆寫。真實每日整合流程也可使用 CLI `daily --paper`。

「同步資料來源」依 `configs/source_plan.json` 下載來源快照並匯出已支援的數值事件；它不等同匯入完整的還原行情。初次研究前仍須使用 `ingest`，確認完整歷史、0050及調整規則，詳見README。沒有足夠資料的任務會明確失敗，不會以示範結果替代。

「評估保留測試」會開封固定版本的最終測試。應先凍結研究設計，開封後保留成功或失敗結果；反覆修改以通過同一保留期不構成未見資料的證據。

## 線上預覽

線上託管版本只讀取合成資料快照，不連接本機或私人Key；執行按鈕全部停用。這可安全分享介面與研究流程，實際資料下載、模型訓練與每日預測需在本機服務執行。

```bash
.venv/bin/python -m twquant --root artifacts/demo export-web --out artifacts/web-preview
```

匯出器拒絕真實行情／預測，排除原始資料、模型、資料庫、金鑰與本機路徑。匯出目錄須獨立於輸入資料及原始碼；只能覆寫帶有本工具標記的先前匯出目錄。GitHub每次main推送會產生7日保存的合成預覽artifact，並不自動部署使用者的真實資料。

## 更新紀錄

原始碼提交至 <https://github.com/Jaa-ack/0050-Predictor>。之後每次授權修改都依 `AGENTS.md` 執行相關測試、Key掃描、文件及CHANGELOG更新、commit與push；保留既有歷史。網頁更新需重新生成合成快照並更新既有Site，避免建立重複網站。

Dependabot每週建立依賴更新PR，不自動合併；CI在push／PR執行。此設定不表示有人持續無人值守修改模型或維運機器。正式每日排程、告警、遠端認證與備份復原仍需另行配置。
