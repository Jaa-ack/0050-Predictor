## 真實行情範圍與完整性

富邦唯讀登入及股票／ETF共104筆成交／五檔訂閱已實測成功；另由正式凍結程式驗證包含IX0001的完整訂閱。收盤或週末的訂閱成功不等於已證明盤中行情完整，第一個實際收集日為11/16。既有Fugle金鑰遭訂閱額度限制，沒有升級或繞過配額。

程式只接受行情公開欄位，不保存驗證回應、帳戶物件或任意額外欄位。憑證仍由伺服器端私人設定讀取；SDK原生日誌與工作輸出留在忽略且受權限保護的目錄，不能作公開除錯附件。沒有交易、帳戶庫存、出入金或訂閱付款呼叫。

行情由[富邦成交頻道](https://www.fbs.com.tw/TradeAPI/docs/market-data/websocket-api/market-data-channels/trades/)、[五檔頻道](https://www.fbs.com.tw/TradeAPI/docs/market-data/websocket-api/market-data-channels/books/)及indices取得。報告標記為**供應商實際揭示成交序列**的前瞻驗證；供應商是否完整傳遞每個交易所個別成交片段仍未核實，不能直接視為嚴格交易所逐成交目標已驗收。

SQLite採WAL與持久化提交。保存訊息事件時間、收件時間、股票與頻道、成交流水號、公開價量及試撮／逐筆階段旗標；重複訊息去重，試撮不作連續交易答案。斷線、執行停頓與時鐘跳動記為缺口，受影響期限答案保守列為未知。只有觀測連續覆蓋完整期限時才將無變價列為逾時。

## 執行與查看

實際工作使用已安裝官方SDK的`artifacts/fubon-venv/bin/python`。三個LaunchAgent使用固定參數陣列與私人來源快照，避免工作目錄後續修改悄悄改變這次規則。行情工作在有效窗口使用`caffeinate`抑制閒置睡眠。

```bash
PYTHONPATH="$PWD/artifacts/live-pilot-20261116-10d/source_snapshot/src" artifacts/fubon-venv/bin/python -m twquant.live_market --root artifacts/live-pilot-20261116-10d --mode status
PYTHONPATH="$PWD/artifacts/live-pilot-20261116-10d/source_snapshot/src" artifacts/fubon-venv/bin/python -m twquant.live_market --root artifacts/live-pilot-20261116-10d --mode report
```

- `protocol.json`：不可混用的設定、股票池、模型與來源摘要。
- `pilot.sqlite3`：實際行情、每日預測、發布封印及資料缺口。
- `access_check.json`：正式程式的訂閱權限檢查；不含憑證值。
- `collector_status.json`：最近收集狀態、訂閱數與佇列積壓。
- `predictions_YYYY-MM-DD.json`及`release_YYYY-MM-DD.json`：每日完整回答及發布封印。
- `evaluation.md`與`evaluation.json`：進度／期末分析、兩期限最弱五檔、逐股與逐日明細、常數漲跌基準、缺報／回退／逾時與延遲樣本。
- `installation.json`：三個排程的標籤、載入檢查與來源版本。

排程需這台Mac保持開機、使用者登入及網路連線。`caffeinate`不會在關機、未登入或合蓋停機時創造行情，也不取代硬體喚醒；停機及漏報會留在完整分母。重啟後LaunchAgent載入專用工作，但不能補發成為當時已存在的預測。沒有設定ChatGPT主動傳訊或雲端收集服務，期末分析由本機排程寫入上述檔案。
