# 有期限的第一次價格變動方向

使用者於2026-11-12接受：每天固定10:00對全部股票發報，預測接下來60秒內第一次價格變動的方向；逾時沒有變動也保留並計錯。這是新增的獨立目標，**不把其成績換成固定秒數後的端點方向或日線收盤方向**。

這條路徑不需要假設90%的市場訂單同向。它研究可觀測的最佳買賣隊列，能否在對稱、零漂移的條件下提供足夠資訊；初始深度、流動性速率與獨立性仍是未經臺灣市場校準的假設。

## 一手來源與適用範圍

[Gould／Bonart原文](https://arxiv.org/html/1512.03492v1)研究下一次中間價變動。表4的大跳動單位股票0.752～0.805是AUC，**不是75%～80%準確率**；小跳動單位股票為0.581～0.642。該研究逐股擬合、隨機切分樣本，並在相鄰價格變動之間取樣，不能當成本系統固定十檔共享模型、逐日固定時間與全部50檔的驗收證據。

[Cont／de Larrard的擴散模型](https://arxiv.org/html/1202.6412v1)提供隊列首次耗盡方向的條件機率。以下採其式44在對稱、零漂移、相關係數0時的化簡，並檢查買隊列歸零應向下、賣隊列歸零應向上的邊界；不是將論文的市場參數套入臺灣股票。[首次穿越時間的反射原理](https://www.stat.berkeley.edu/users/pitman/s205s03/lecture17.pdf)允許直接抽取精確邊界到達時間，避免時間離散化漏掉短暫跨界。

[VisualHFT於2026-11-09公布的工作論文](https://visualhft.com/research/lob-imbalance/)在四個保留日、100檔Nasdaq股票的事件樣本中報告55.1%命中率。它研究十檔深度加權量測、排除超過30秒才出現下一次變動的區間，與本系統的固定時點、完整分母及最佳隊列模型不同；不是本模型的外部對照成績，也不能提供臺灣全部50檔75%的預期。此輪僅查核來源，未把外國資料或權重加入訓練。

## 解析條件

令最佳買／賣深度為`q_b,q_a`，兩側在首次耗盡前各自遵循相同擴散速率`σ`的獨立零漂移Brownian過程，並令`I=(q_b−q_a)/(q_b+q_a)`。無期限的向上機率為：

`p_up = 1/2 + (2/π) atan(I)`

策略在`I≥0`時預測上漲，否則下跌；不篩選小不平衡日。若固定發報時點的兩側深度各自服從均值1的獨立指數分布，`I`均勻分布於`[-1,1]`，因此平均方向正確率可解析積分為：

`A_∞ = 1 − log(2)/π = 77.9364%`

這是初始深度分布加上動態假設的結果，**不是直接設定分類器正確率**。模擬先抽過去可知的深度，再以獨立未來常態亂數產生兩側首次到達時間`τ=(q/(σ|Z|))²`；先耗盡賣側才使中間價向上，沒有條件抽取正確答案。

期限為`T`時，無事件機率為`p_timeout = erfcx(σ√(T/2))²`，其中`erfcx`是縮放互補誤差函數。在逾時不給分的完整分母下，同一不平衡正負號策略滿足：

`max(0,A_∞−p_timeout) ≤ A_T ≤ min(A_∞,1−p_timeout)`

在此正規化單位、`σ=1`時，30秒下界為75.9417%，60秒下界為76.9089%。這些界限假設當前隊列可即時供推論，沒有把資料接收、運算或實際發報延遲藏入已驗證的市場成績。

令`a`為與深度及未來獨立的輸入可用率；缺報仍輸出固定十檔訓練先驗。在對稱分布中，這個固定方向回退的正確率是`f=(1−p_timeout)/2`，因此完整覆蓋的下界為`a×max(0,A_∞−p_timeout)+(1−a)×f`。不能把回退直接視為0.5，也不能以不發報代替缺報。

一般`Gamma(k,1/k)`深度使相對深度服從`Beta(k,k)`，用來測試較平衡或更偏斜的隊列。`k=2`時，無期限最優值已約71.7884%，因此不能由指數深度的77.94%推論所有弱股也能達標。初始分布是在固定時點直接假定，沒有證明它是完整市場造市過程的穩態分布。

## 共享模型與固定研究

三候選為共享方向先驗、單一不平衡logistic，以及不設截距的對稱logistic。每組僅以固定十檔600日期訓練、200日期校準選模，並以2000日期完整測試50檔。缺報訓練列保留，推論時使用共享訓練先驗；外部股票不提供係數、補值、校準或選模資訊。

對稱logistic若學到正斜率，其決策等同上述解析策略。一般logistic的截距會移動門檻，必須依實際係數另計期望，不能直接借用理想策略的77.94%。本輪會逐筆重建候選機率，並用選中模型的實際門檻計算條件下界。

`configs/first_change_study.json`固定三種子、30／60秒最大等待及七情境：指數深度、`k=0.5`、`k=2`、較慢擴散、25%共同缺報、五檔外部隊列更平衡及五檔外部活動較慢，共42組及126個模型稽核。

```bash
LOKY_MAX_CPU_COUNT=1 .venv/bin/python -m twquant direction-first-change-study --config configs/first_change_study.json --membership artifacts/current-membership/20261107/membership.json --out artifacts/first-change-new-run
```

所有列都保留；答案若在期限內未發生，標記逾時並計錯，資料不足以證明有無事件則保留未知答案並計錯。原端點模型及稽核會拒絕明確標成此新目標的資料。指數沒有委託簿，使用獨立抽象指數點數與先驗回退，不可交易，也不以ETF委託簿替代。

這仍是合成平日日曆、理想化已知時間及計畫發報時間。真實標籤需要完整且可排序的逐事件行情與本地到件證據；秒級快照不能證明中間沒有更早的價格變動。未啟用行情接收、排程、付費服務或交易。

42組、126個模型稽核已獨立重算，全部標的／日期、逾時、缺報回退及轉移失敗均保留。下表為三種子的最弱五檔樣本準確率；不是固定端點或日線成績。

依已選模型的實際斜率／截距重建決策門檻後，指數深度情境的全50檔母體平均下界為：30秒75.9325%～75.9417%，60秒76.9021%～76.9089%。這提供不必先取得全部資料的條件式75%設計推導；仍需所宣告深度分布、動態、輸入可用率及即時性成立。較弱外部深度或慢活動的失敗，不能靠選取有利股票排除。

另作延遲敏感度：若觀測後隔`l`才發報，把發報前已首次跨界的案例一律計錯，不挑掉這些日期。這是保守的可用事件診斷，**沒有模擬先跨界後重新掛單的完整「發報後下一次變動」過程**，不能當成實盤回測。指數深度、單位擴散下，原不平衡正負號策略的解析下界為：

`A_∞ − P(τ>60+l) − P(τ≤l)`

母體期望的條件下界與有限樣本挑出的最弱五檔是不同量。下界低於75%不證明完整真實過程一定低於75%，但理想策略的餘裕已不足以直接支持現有行情接收／推論系統的75%設計預期。不能將合成資料的計畫時間或理想5毫秒已知標記當成已量測的實際發報延遲。

獨立核對使用另一組分布API重建全部首次到達標籤，事件時鐘在2奈秒內一致；全部候選機率由記錄的係數重建，校準選模只含固定十檔。外部干預不改主要模型或其餘標的；另已重擬合固定十檔並逐筆重現全部53個查詢標的，以及舊端點四候選機率。
