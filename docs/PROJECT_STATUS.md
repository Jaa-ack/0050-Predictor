先驗證低成本日線及公告因子，再增加只有較短歷史的分K／逐筆／新聞。不同來源年限不同時，分為長期基準與較短期增強實驗；不能為了增加欄位而把多年樣本全部縮成最近數月，也不能補造早期新聞。

現有Key主要解決認證；最關鍵的剩餘資源是**有時間版本的真實歷史資料、可確認的來源方案、資料科目與單位字典，以及未參與模型選擇的未來驗證時間**。資源設定與已核對官方入口見 [DATA_SOURCES.md](DATA_SOURCES.md)，既有模型限制見 [GAPS.md](GAPS.md)。
