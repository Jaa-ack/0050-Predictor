# 盤中方向研究設計

使用者於2026-11-12同意研究較短盤中未來區間，仍要求每天對任意五檔完整預測。此擴充提供新的研究方向，現有資料與來源仍不足以合理預期任意五檔75%；不需要等資料齊全才指出這項限制。

## 一手來源與適用範圍

## 本輪固定的比較契約

- 原日線1／5／20交易日研究及其結果保持獨立。盤中先定每個主要交易日臺北時間10:00的一次共同預測，30秒為主要設計，1／5／60秒分別列為次要研究；不可看外部股票結果後挑期間、時間或五檔。
- 原始端點中價`(best_bid+best_ask)/2`相對決策中價上漲或下跌。盤中保守主指標只給真正上漲／下跌的正確答案得分；平盤仍占分母並另外揭露。既有日線「上漲／非上漲」定義不變。
- 每天全部50檔皆需輸出同模型、同門檻的二元預測。低信心或缺輸入回退共享訓練先驗，不能棄答；缺答、無法判定端點、平盤及最弱股票都不能刪除。合成證據單獨標示。
- 交易日來自獨立的主要交易日曆；不可從有行情的日期反推完整日曆。每一期間固定相同時刻、相同日期及同一分母；最弱五檔平均即全部2,118,760個五檔組合的最小平均，並另要求最低單檔達標。
- 只有在輸入到件時間不晚於發報、發報不晚於決策時才算有效；端點必須是決策加固定秒數。不能把事後確認的下一次跳動事件，冒稱事前可設定的固定秒數預測。
- 決策與端點須在正常連續交易時間內，保留中斷／試撮／漲跌停日的缺漏或平盤。證交所區分[連續交易、收盤集合競價及盤中暫緩撮合](https://wwwc.twse.com.tw/en/products/system/trading.html)；不能使用試撮價格製造可交易行情。

## 可採納的共享模型設計

輸入是預測前已收到的最近100個最佳五檔委託狀態、時間差、價差、各檔量比及過去委託簿變動。價格相對當前中價／價差的機械換算可用於外部股票；任何學習式補值、標準化、校準及候選選擇只用固定十檔。不能對外部股票另擬合轉換器、做線上權重更新或將其加入同儕注意力。

第一層控制為共享先驗與不平衡logistic；現已提供[合成隊列過程研究](QUEUE_SIMULATION.md)，並加入歷史路徑logistic／hist控制。序列網路候選可用五檔輸入的因果卷積加LSTM，另與較小的因果TCN比較；這兩種網路仍**尚未實作或訓練**，不能把稽核或樹模型稱為DeepLOB預測後端。原論文十檔深度須改為五檔，這項改動也讓原分數更不能直接沿用。

唯一擬合／校準／選模集合仍為2330、2454、2317、2308、3711、1303、2383、2881、2891、3037。其餘成分股及0050／1216／2002／2412均僅作同模型推論；IX0001／TAIEX仍是不可交易的外部指數。指數沒有同等股票委託簿時，保留缺報與共享先驗，不捏造委託簿或以ETF替代指數答案。

固定十檔跨日期切分、成熟標籤清除、完整保留期及按市場交易日的區塊不確定性檢查，均須在實際序列研究中保留。現有日線保留期不能因新增盤中分支而開封；未來驗證路徑也不是完成當前設計評估前必須等待的條件。

## 資料能力與限制

[Fugle官方Books介面](https://developer.fugle.tw/docs/data/websocket-api/market-data-channels/books/)提供最佳五檔、時間及交易階段標記；掛單可不足五檔，最佳價格為0可能代表市價委託。不能將空陣列／0當成有效中價，也不能將聚合深度變化冒稱完整逐筆新增、撤單或交易者身份。

未來本機接收器須另外保存本機到件時間、連線狀態與中斷紀錄。現在的REST即時報價擷取，不是歷史逐筆簿重播；供應商時間也不是本機到件時間。資料權限、同時訂閱數、延遲、漏包與跨通道順序尚未量測，這些都應進入可行性條件，不能預設完整。

此設計沒有啟動行情連線、排程、訂閱、花費或下單。

## 不依賴高斯假設的資訊需求

令`u`為無法確認答案比例、`z`為已知答案中的平盤比例、`q`為可判漲跌樣本的完整訊號可用率，`p`為其可用時準確率、`b`為回退準確率。主指標的條件期望為：

`A = (1-u) × (1-z) × [q×p + (1-q)×b]`

這是各條件分組的全機率分解，不假設錯誤獨立，也不把訊號可用率當預測覆蓋率。每一股票需分別評估；市場同步中斷、不同股票的平盤率及轉移品質不能用總體平均掩蓋。

例如假設`u=0.005, z=0.10, q=0.98, b=0.50`，欲達75%需`p`約84.44%。假設可用訊號準確率80%時，完整分母只能約71.10%；假設85%時約75.49%。這些是**反推要求與條件算例，並非從文獻估得或本系統測得的市場機率**。若已知答案30%平盤，即使方向完全可預知、沒有缺報，主指標上限也只有70%。

因此盤中路徑比日線更有具體的委託簿訊息來源，但仍須解釋最弱五檔能否提供所需訊號品質；引用三類、AUC、平滑標籤或大量不變價格下的高命中率，都不足以支持本目標的75%預期。

## 已實作的驗收介面

`twquant.direction_intraday.audit_intraday_predictions`接受預測表、完整50檔名單、獨立決策時間表、固定秒數與證據種類。必要欄位為`ticker`、`decision_at`、`target_at`、`prediction_at`、`max_input_available_at`、`actual_return`、`probability_up`、`decision_threshold`及`model_version`；時間須有時區，答案應由原始端點中價建立。

```python
from twquant.direction_intraday import audit_intraday_predictions

report = audit_intraday_predictions(
    predictions, constituents,
    expected_decisions=primary_calendar_at_1000,
    horizon_seconds=30,
    evidence_kind="historical",
)
```

介面重新建立完整日期乘50檔網格，報告平盤、缺預測、未知答案、無效發報、最低單檔及最弱五檔。`up_vs_nonup_accuracy_diagnostic`只作對照，不代替盤中主指標。每日期須共用模型與門檻；宣告時間本身無法證明原始行情、特徵或訓練隔離，故`empirical_target_met`與`real_world_target_verified`保持`false`。`full_coverage_sample_gate_met`僅表示所給樣本的分數、基線優勢、完整性與最少126交易日條件通過。

這項介面以合成反例驗證：75%平盤加25%下跌、每天猜非上漲可有100%的非上漲對照命中率，但真正漲跌得分只有25%；整體90%仍可能有最弱五檔0%。這些測試驗證記帳規則，不是新預測模型的成績。

已另提供[本機快照到因果特徵矩陣](INTRADAY_BOOK_INPUTS.md)，保留獨立端點、實際到件上界及跨單位特徵；該接口尚不是已驗證的供應商接收器或實際發報後端。另見[集合競價目標區別](AUCTION_DIRECTION_SCOPE.md)，不同參考價格的準確率不可互換。
