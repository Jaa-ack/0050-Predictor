# 成交價首次變動的毫秒延遲評估

本輪評估固定共享價差反彈策略在毫秒延遲下的完整覆蓋表現。目標沿用使用者已接受的定義：每天10:00預測全部50檔，評分發報後60秒內第一個不同成交價格；同價成交繼續等待，逾時、未知與缺報日都保留。這些成績與中間價、固定60秒終點及日收盤方向分開報告。

反彈策略根據截止前最後成交價相對買賣中間價的位置預測反向變動，缺報時仍發出固定十檔訓練先驗的回答。固定十檔是唯一訓練、補值、校準及選模來源；其餘成分股與0050、1216、2002、2412只接受同一模型查詢。IX0001保留先驗查詢及未知的成交價答案，指數不建立虛構委託簿。

## 事先固定的條件

[設定檔](../configs/operational_first_change.json)在主要擬合前固定600訓練、200校準、2000測試日期、三個新種子101／137／173及以下十二情境。每情境三種子，共36組、144個候選稽核；每組保留50檔各2000筆預測及三個額外轉移查詢。日期為明示的合成平日，並非臺灣歷史交易日。

|情境|輸入截止至發報的延遲|人工條件|
|---|---|---|
|限價較多|100微秒、1、5、20毫秒|15%激進單、35%撤量、50%被動限價；每秒100事件|
|限價較多且有大單|1、5毫秒|另10%激進單改為16或32單位|
|外部五檔較快|1、5毫秒|只將1216、2303、2327、2345、2357改為每秒1000事件|
|2%共同缺報|1、5毫秒|仍每天回答，保留先驗回退與完整分母|
|中間比例|1、5毫秒|35%激進單、25%撤量、40%被動限價|

普通單量1至4單位的比例為60%／20%／10%／10%。買賣方向使用中立流量，事件等待時間獨立；本輪未加入有方向的訂單拆分、消息共同衝擊或完整日間季節性。比例、到達率、單量、初始深度與固定時點分布均為未校準的情境假設。「中間比例」不表示市場中央估計。沒有看過新測試結果後刪除情境或替換種子。

固定反彈在擬合前指定為設計候選，另完整比較共享先驗、logistic及hist。比較政策只依固定十檔校準期最低單檔、平均與事先候選順序選模；外部標的不參與選擇。先前陣列介面的推論速度只適用固定反彈，不能套用到其他模型。

沿用[逐價撮合研究](MATCHING_FIRST_CHANGE.md)的價格層級部分成交、逐價消耗、獨立買賣報價及有限已知深度。發報前成交繼續更新實際錨點；答案使用發報後第一個不同的個別價格片段。深度不足與運算預算不足保留未知，不重設報價或補出虛構深度。本輪不改任何Python實作，來源指紋為`040664e16282ea9061920579ac630b9664f21ed11d78093964390434fe5bbdf9`。


固定反彈與所選政策均有27／36組通過任意五檔75%的完整樣本門檻，既有最低單檔及方向基準優勢輔助門檻也同樣通過27組。以原始任意五檔平均為準，兩政策各20／36組的共同條件抽樣下界達75%；更嚴格的最低單檔下界則分別為固定反彈14組、所選政策16組。兩項統計分開報告。

1毫秒限價較多情境的固定反彈任意五檔共同下界為78.015%～78.508%；較快外部五檔為75.404%～76.169%。加入大單後為74.671%～75.329%，僅兩種子通過，未將未通過的種子略去。5毫秒加入大單只剩72.570%～73.413%的下界，20毫秒及較快外部五檔5毫秒也未達樣本75%。

全36組的50檔答案均在事件預算內解決，沒有成分股逾時或未知；IX0001每組仍保留2000個未知成交答案。缺報只降低可用輸入，沒有刪除任何預測。較快外部干預不改主要訓練、校準或其餘標的；各延遲版本的截止前特徵保持相同。

以上建立約1毫秒新鮮度下的條件式可行路徑，也顯示委託比例、較大單與更高活動會縮小裕度。中間比例1毫秒雖有77.66%～78.08%的最弱五檔樣本分數，對應共同下界僅73.572%～74.015%。不同過程不能混成一個有市場意義的預期，也沒有把中立流量的高分當作有方向連續下單或消息衝擊下的保證。

以更保守的最低單檔下界估計額外失敗預算：限價較多1毫秒為77.277%，5毫秒為75.467%。若每檔最多另有q比例的列相對參考過程任意改變，每列最多損失一筆，保守正確率下界為p−q。因此維持75%的額外空間分別只有2.277及0.467個百分點。這個計算需要明確的過程對應前提，沒有實測或假定真實市場的q。

來源快照、設定與環境在擬合前固定；本地`artifacts/operational-first-20261114-v1`保留全部機率、144個候選稽核與獨立核對。核對包括全部四候選只用固定十檔重新擬合、53標的逐筆機率、完整每日分母、個別成交片段及時間、1400筆獨立字典委託與96條標量歷史／未來路徑；後者含13條發報前已變價及11條逾時，時間誤差不超過0.978奈秒。主實驗沒有逾時，不代表參考與退化情境的逾時可省略。

## 如何驗收任意五檔

每組以50檔各2000日期的完整分母計算逐股正確率，最低的五檔平均就是全部2118760種五檔組合中最差的平均；不挑股票、不略過難日。最低單檔另列為更嚴格的診斷，不以它取代原本的任意五檔要求。

固定反彈與依主要校準期所選政策沿用事先宣告的共同家族：兩政策×50檔×36組，共3600個單側Clopper–Pearson界限，家族錯誤率5%。若全部逐股真實正確率同時不小於其下界，則任意五檔平均也不小於五個最低下界的平均；這個推導沿用同一家族，不另挑模型或刪除股票。另報最低單檔下界及既有方向基準優勢的輔助門檻。

這些界限只描述已宣告人工過程中的日期抽樣誤差，沒有把未知市場分布誤差納入。操作條件、委託序列相關性、消息衝擊與行情完整性是否適用，仍需分別評估；不把共同抽樣下界稱為實際市場75%保證。

## 公開證據與參數意義

[Citadel Securities於2022年3月發布的市場分析](https://www.citadelsecurities.com/wp-content/uploads/sites/2/2022/03/Market-Lens_Continuous-Trading-vs-Frequent-Batch-Auction.pdf)比較2020年3月23日前後各一年，以五秒取樣的前五檔累積深度描述流動性改善，並使用短期波動代理價差。這能支持研究委託簿深度，但沒有提供本輪的事件比例、50檔10:00狀態或首次成交變動準確率。

[Indriawan、Pascual與Shkilko的2021年11月14日版本](https://acfr.aut.ac.nz/__data/assets/pdf_file/0008/578429/Ivan_TWSE_15Nov2021.pdf)研究100檔大型股，樣本為2019年11月至2020年7月。其表5以最佳買賣量平均定義報價深度：改制前後分別為427.73與323.48千股，報價價差為23.05與24.48基點。它與前五檔累積深度不同，不能挑其中較有利的數字當成本系統校準。該文排除鎖定／交叉報價及依單筆規模位於最高1%的鉅額交易，並對連續指標縮尾；其彙總結果也不能取代本專案保留全部日期、大單與弱股的分母。

這兩份研究的時間窗、控制組與深度定義不同，亦未提供現今全部50檔的聯合深度／單量分布。文獻的毫秒時間戳記代表時間精度，沒有保證本系統的傳輸或發報延遲。此處核對公開文字與表格擷取；直接PDF下載回應403，未聲稱完成本地圖表逐像素檢查。

## 行情接入條件

[富邦成交頻道](https://www.fbs.com.tw/TradeAPI/docs/market-data/websocket-api/market-data-channels/trades/)列出成交價格、時間、流水號及試撮／逐筆階段旗標；[委託簿頻道](https://www.fbs.com.tw/TradeAPI/docs/market-data/websocket-api/market-data-channels/books/)提供最佳五檔與時間。兩者需保持各自來源及本地收件時間，不能用較晚到達的報價回填較早的預測。

[模式說明](https://www.fbs.com.tw/TradeAPI/docs/market-data/websocket-api/upgrade-guide/)列出Speed與Normal選項，但沒有本專案的數值延遲保證。[HTTP說明](https://www.fbs.com.tw/TradeAPI/docs/market-data/http-api/getting-started/)列出查詢端點與速率限制；輪詢快照也不能證明已保留期限內第一個成交價格片段。

可執行設計需維護最後有效成交與報價狀態，在固定發報時間讀取預備陣列，記錄來源時間、收件時間、實際發報時間及模型版本。試撮、重連、缺口、過期輸入與未知答案保留明確狀態並照常回答。可驗證的首次變動標籤另需完整成交順序及資料完整性契約；單一流水號欄位、模式名稱與微秒格式時間戳記都不足以證明該契約。
