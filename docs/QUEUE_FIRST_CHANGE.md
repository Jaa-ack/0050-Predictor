# 離散隊列、事件時鐘與發報後首次變價

這是已接受的[有期限首次變價目標](BOUNDED_FIRST_CHANGE.md)的另一個過程檢查。前輪獨立Brownian隊列可解析出部分超過75%的條件式設計，但初始深度分布與理想到件會強烈影響結果。本輪使用整數隊列、單筆數量、明確事件時間與完整發報前演化，檢查這些假設是否仍提供足夠訊息。

每天固定10:00對全部50檔發報，預測其後60秒內的第一次中間價變動。沒有變動仍計錯，未知答案仍占分母；固定十檔是唯一訓練、補值、校準與選模來源。0050及其他轉移標的沿用同一組模型，指數沒有委託簿，也不交易。

## 時間與標籤

```mermaid
flowchart LR
    H[截止前100個觀測事件] --> F[不平衡與事件歷史特徵]
    F --> M[固定十檔共享模型]
    M --> E[10:00發報]
    H --> U[截止至發報的未觀測事件]
    U --> R[可能先變價並重新掛單]
    R --> T[發報後第一次變價]
    E --> T
```

輸入截止為`10:00−latency`；預測在10:00發出。截止後每個事件另抽一個獨立指數等待時間，`Δt=−log(1−U)/event_rate`。時間座標與16個隊列事件座標分開，不能拿隊列重設用的亂數兼作等待時間。

發報前的成交、撤單、掛單、壓力翻轉、價格變動及隊列重設均繼續模擬，**不把第一個截止後變動誤當成發報後答案**。例如：發報前先上漲並重設，發報後再向下，答案應為向下；發報前的事件也不會因無法得分而整列刪除。

發報後超過60秒才有下一個事件，才能確認逾時。若2048個未來事件的運算預算先用完，答案保持未知，不能冒充逾時；測試列保留並不得分，未解決的主要訓練／校準列會使該凍結研究停止，不能靜默刪除。

過去100事件只用來產生截止時點的初始隊列及事件序列摘要。這不是100秒，也沒有證明該暖機分布等於市場固定鐘點的穩態分布。新模型要求`history_window_unit=events`，拒絕標成秒數的序列；觀測時間與發報時間仍為合成宣告，沒有量測真實行情延遲。

## 物理假設與模型

[Cont／de Larrard原文](https://arxiv.org/html/1104.4596v1)以Poisson到件、整數買賣隊列及耗盡後補單連結時間與價格。本輪只借用此機制方向，不是其模型複製或臺灣參數估計。

沿用本專案五檔隊列過程：65%市場移除、15%撤單、20%新增，最佳隊列耗盡使抽象中間價移動一跳並重設兩側深度。中性情境的市場買／賣各半，不假設90%同向訂單。單筆數量為1至4單位，分別比較等機率與`[60%,20%,10%,10%]`；後者是事先指定的反事實分布，**不是臺灣市場已校準的單筆量比例**。原端點與資訊上限研究的預設單筆量規則維持不變。

新增的事件歷史logistic只使用當下相對深度、不平衡，以及過去5／20／100事件的摘要。它不讀隱藏壓力、流動性係數、發報時的實際隊列或未來答案；外部股票只提供自己的可觀測查詢輸入。三個原先候選（先驗、不平衡logistic、對稱logistic）保持為匹配控制。

壓力翻轉係數在這個過程中是每事件危險率，事件到達率才是每秒單位；不能把之前每秒一事件的係數原樣解讀成新的每秒危險率。無委託簿的指數使用獨立抽象點數Poisson事件及共享先驗，不以ETF或虛構指數委託簿替代。

## 事先固定的比較

`configs/queue_first_change.json`固定三種子、600訓練日期、200校準日期、2000測試日期、60秒期限及四候選。十二個情境共36組、144個模型稽核：

|情境|事先指定條件|
|---|---|
|均勻單筆量、零延遲|1至4各25%，每秒100事件|
|小單較多、零延遲|1至4比例60%／20%／10%／10%|
|1／5／20／100毫秒|其餘相同，完整處理延遲期間的事件|
|較慢活動|每秒1事件、5毫秒延遲|
|共同缺報|25%日期輸入缺報，保留共享先驗回退|
|中等方向壓力|給定隱藏壓力的同向市場訂單機率60%|
|外部五檔單筆量改變|只有五個外部標的改為1至4等機率|
|外部五檔較快|只有五個外部標的改為每秒1000事件|
|混合流動性|中等壓力，係數0與1.5各半，模型不能取得係數|

外部五檔為1216、2303、2327、2345、2357，不屬固定訓練十檔。每組只依固定十檔校準期的最低單檔、平均、候選順序選模；另重算同一校準資料下的三候選控制，不能看測試答案挑選控制。全部日期是明示的合成平日，不是交易所歷史。

36組全部完成；每組保留2000測試日期、50檔成分股及三個額外轉移查詢，四候選共144個稽核。表中為三種子的範圍，沒有挑掉較差種子或股票：

|小單較多、零延遲|66.86%～67.51%|66.55%～66.90%|
|1毫秒|66.52%～67.20%|66.35%～66.70%|
|5毫秒|65.31%～65.56%|64.55%～65.30%|

|中等方向壓力|66.22%～68.53%|65.70%～68.15%|

全部36組均未達75%，沒有把失敗改稱資料不足而移除。全部未來路徑在預算內解決，本次樣本沒有逾時；未知與逾時行為另以手工路徑測試，共同缺報仍按原規則計分。新事件歷史候選相對同校準資料選出的三候選控制，最弱五檔差異為−1.55至+2.31個百分點，36組中15組選到它，沒有穩定優勢。這些結果不能推翻另一個人工Brownian過程的解析式，但說明其深度分布、動態與即時性假設會左右結論；不能只因理想式超過75%，就推定現行系統已具有合理市場75%預期。

每秒100事件的5毫秒情境，約4.91%～4.93%的成分股測試列在發報前已變價；20毫秒為19.41%～19.59%，100毫秒為77.37%～77.51%。這些列全部繼續模擬下一次發報後變價，沒有刪除，也沒有把舊變動當新答案。上述比例只屬宣告的人工事件率，不能當作實際行情延遲量測。

獨立核對重建全部144個模型稽核、固定十檔校準選擇及事件歷史模型，另以純量程式逐步核對過去特徵、獨立事件時鐘、發報前重設及發報後標籤。外部單筆量／到達率干預不改主要模型、校準或其餘股票；零至100毫秒比較的觀測特徵逐筆相同。舊隊列面板及三個Brownian候選的機率也保持逐筆一致。

數值協定與來源快照保留在本地`artifacts/queue-first-20261113-v1`。數值核對完成後僅更正新模型的公開標籤說明與逾時計數欄名；另外保存來源附錄，核對運算AST及新擬合的全部53標的機率，沒有重寫原協定或歷史數字。

## 真實行情接入的缺口

截至2026-11-13查核，[富邦Books](https://www.fbs.com.tw/TradeAPI/docs/market-data/websocket-api/market-data-channels/books/)列出時間、五檔價格／數量及交易階段，未列出委託簿訊息序號或逐事件完整保證。[富邦Trades](https://www.fbs.com.tw/TradeAPI/docs/market-data/websocket-api/market-data-channels/trades/)及[Fugle Trades](https://developer.fugle.tw/docs/data/websocket-api/market-data-channels/trades/)有`serial`、時間、成交價及買賣價，但文件未在這些頁面定義可據以證明無缺口的序號範圍。不能將訂閱成功、單一時間戳或流水號直接當作完整性證明。

真實標籤仍需來源事件排序、交換所／收件時鐘、重連與缺口紀錄，以及實際發報時間；有缺口的答案保留為未知。這是資料契約需求，沒有啟用供應商連線、排程、訂閱或交易。

使用者於2026-11-13另接受包含買賣價差反彈的「成交價首次變動」。本頁及本輪程式仍只評估中間價，後續成交價研究需獨立標籤與反彈基準，不能挪用本輪分數。
