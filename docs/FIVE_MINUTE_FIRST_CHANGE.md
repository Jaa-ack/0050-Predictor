# 5分鐘內成交價首次變動的獨立驗收

使用者於2026-11-14接受每天10:00預測接下來300秒內第一個不同成交價，含買賣價之間的成交反彈；全部50檔每日必答，逾時與未知仍計錯。[60秒結果](DEPTH_CLOCK_FIRST_CHANGE.md)保留原來的期限、來源摘要與成績，未直接更名為5分鐘證據。這也不是10:05端點價格、中間價、可交易報酬或日收盤方向。

**新增了可執行的300秒驗收與共享模型轉移。** 下列數字是明列深度、事件流與延遲假設的合成研究；尚未以目前50檔的真實聯合分布校準。支持的是有條件的設計候選，不能宣稱市場75%已被證明。

## 設定與資料邊界

[設定](../configs/depth_clock_transfer_300.json)在評分前凍結十二深度／方向／流量條件、種子401／443／487、兩種速度，共72組，每組50檔各2000個合成平日。來源條件與全部失敗對照見[深度研究](DEPTH_CLOCK_FIRST_CHANGE.md)。

兩種速度為一般股票每秒1／0.1事件、截止至發報延遲100毫秒／1秒；外部快股仍為十倍事件率。兩者由來源每秒100事件／1毫秒同時縮放率與延遲，保留相同輸入事件數、發報錨點與未來事件序列，因此不是獨立新增的72組市場樣本。輸入窗口按事件數計算，時鐘變慢後覆蓋的實際時間也變長。

每種子只以預先指定thin_p50情境的固定十檔600訓練日期擬合一次spread_bounce，沿用60秒訓練標籤與相同模型版本查詢300秒；沒有加入外部股票、改動模型、重新校準或挑選最佳測試情境。方向規則讀取截止前成交在最佳買賣報價間的位置，缺報時仍發共享先驗。所有53標的查詢保留；IX0001不建立指數委託簿，其成交答案為未知，不參與50檔成分驗收。

實作將原始首次變動延遲乘以整數slowdown，再按300秒重新判斷。必須滿足300/slowdown不超過來源60秒可觀測窗口；例如slowdown=1的延長被拒絕。原始未知仍未知，原有逾時不臆造新事件。來源逐筆檔案與來源快照皆先檢查SHA；僅允許經AST核對的300秒交易目標驗證擴充，其他撮合與模型語義必須相同。

在中間委託比例、方向強度0.5的條件下，每秒0.1事件／1秒延遲的最弱五檔為90.45%～90.77%，共同下界87.43%～87.79%；同速度60秒只有47.53%～48.41%。但深度對照deep_p50仍只有73.63%～74.21%，外部薄深度為66.93%～67.68%，較強持續性亦保留失敗。延長等待解決部分逾時，沒有普遍補足方向資訊。

每列為三種子的範圍，表內最弱五檔平均涵蓋任何五檔的平均要求，最低單檔仍另存。共同下界使用50×72=3600個單側Clopper–Pearson界限、家族錯誤率5%，再平均每組最低五個逐股下界；僅處理人工分布內的抽樣不確定性，未涵蓋市場分布錯置。

60秒與300秒的成績各自重算：相同速度、模型與日期下，延長期限只會增加已知首次變動的可得答案，並不改變方向或預測機率。每秒0.1事件／300秒恰與原60秒／每秒0.5事件具有相同事件曝光量，兩者正確次數相同；時點、延遲、期限與比較家族仍分開記錄，不能將這個配對視為第二份獨立證據。
