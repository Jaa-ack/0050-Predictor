# 首版本機系統的缺口紀錄

此表記錄多來源整合前的首版狀態。已新增七來源連接器、FRED vintage／美股／財務特徵匯出、ETF持股下載、官方公開快照及Key保護；最新狀態與剩餘工作以 [PROJECT_STATUS.md](PROJECT_STATUS.md) 及 [DATA_SOURCES.md](DATA_SOURCES.md) 為準。以下未實作的模型／成交／統計驗證限制仍適用。

目前版本提供可執行的本機研究、歷史回測、影子預測與到期評分流程。程式測試與合成資料演練只能驗證流程；真實行情是否具有可持續的預測優勢，必須另外取得資料與樣本外證據。

## 設計與目前實作的差距

| 環節 | 目前實作 | 尚缺內容與影響 |
| --- | --- | --- |
| 臺股日行情 | FinMind 原始／還原行情介接、嚴格格式驗證、可驗證 CSV 匯入 | 尚未替使用者取得合格帳號、資料授權及完整真實歷史快照；帳號有金鑰不等於具有還原資料權限 |
| 公司行動 | 原始 OHLC 與還原收盤價分開保存，以同日調整因子換算報酬和成交價格 | 需要供應商還原規則、除息／分割／減資事件核對、不同下載版本的變更查核；不能把原始收盤價冒充還原收盤價 |
| 十年以上資料 | 可匯入長期資料，保留快照與來源；升級檢查基準至少十個曆年且 2,000 個交易日、各目標至少 504 日 | 尚未交付十年以上真實資料；2,000 個交易日本身不等於十個曆年。較新公司僅保留實際歷史，目前門檻也不代表每檔都有十年資料；擴充訓練股票池仍待完成 |
| 歷史當時可得性 | 資料與事件有 `available_at`，事件有 `published_at`，修正數值按可用時間合併 | FinMind 回補日行情以臺北時間 20:00 重建可用時點，屬研究假設，並非歷史實際收件紀錄；仍缺逐期公告、延遲與修正版本的可稽核檔案 |
| 原始資料與重現 | 不可覆寫下載檔、Parquet 快照、雜湊校驗、DuckDB 查詢；預測與結果分開存入 SQLite | 尚缺外部不可變更備份、保留期限、自動復原演練與多人同時更新管理 |
| 研究股票範圍 | 固定十檔目標股票與 0050；模型共用跨股票資料 | 名單來自使用者提供的 **2026-11-02 未獨立核實快照**；尚未自動取得最新前十大，亦無歷史成分、權重、公告及生效日期，因此不能稱為歷史前十大輪動策略 |
| 市場時點 | 盤後 20:00；歷史盤前使用下一個實際 0050 交易日 08:30；正式盤前須有已驗證日曆 | 尚缺官方交易日曆自動更新、臨時休市檢查、各資料源的公布時程與延遲監控；合成資料只有平日曆 |
| 夜盤、美股、匯率、總經 | 可透過有時間戳記的數值事件 CSV 接入特徵 | 尚無自動下載、交易所時區／夏令時間對齊、夜盤交易日歸屬、期貨換月及資料授權整合 |
| 法人、融資券與財報 | 數值事件及估值輸入介面已備妥 | 尚無自動抓取、單位整理、公告原文保存、歷史修正檔與分析師預期差資料 |
| 新聞與事件 | 接受已結構化、附可用時間的事件數值 | 尚無新聞授權、去重、股票對應、繁體中文事件模型、意外程度／新穎性模型；沒有實作新聞全文直接預測股價 |
| 多期間價格模型 | 1／5／20 日共用模型；Ridge／邏輯斯迴歸基準，加直方圖梯度提升模型的固定融合 | 尚無獨立市場預測模型、個股殘差／超額報酬模型、產業專屬模型、股票個別校準；歷史權重不足時只使用等權排除自身的同儕代理因子 |
| 機率與區間 | 時間切分後的機率校準、約 80% 歷史殘差區間與實際涵蓋率追蹤 | `q10/q50/q90` 是現行相容欄位名稱，並不代表正式條件分位數模型；中央值是對數報酬轉換值，尚無簡單報酬期望值的殘差偏誤修正 |
| 基本面估值 | 製造業 FCFF 折現、金融業合理 P/B、明確 EPS／P/E 輸入的備用估值；三種情境及假設 | 尚缺可驗證財報自動供料、未來 EPS／現金流預測、產業同儕倍數與模型適用性驗證；範例財報為合成資料 |
| 解釋 | 顯示標準化線性基準的貢獻代理值 | 尚無融合模型的 SHAP 解釋、穩定性驗證與因果推論；基準代理值不能當成整個模型的重要度 |
| 回測 | 按日期分組、擴張式訓練、標籤到期與可用時間隔離、基準比較、成本與現金配置；預留最後 126 個市場交易日，凍結政策／程式／快照後另行一次開封 | 保留集流程已實作，尚無合格真實資料的最終開封證據；仍缺區塊自助抽樣信賴區間、多次試驗偏誤修正與完整市場狀態分析 |
| 成交與風險 | 一日訊號採下一開盤買入、當日收盤賣出、隔夜空手；限制檔數／權重、計算雙邊費用與稅；無法成交保留現金 | 尚無委託簿、漲跌停排隊／部分成交、開收盤撮合容量、整股／零股與最小下單金額、隨流動性變化的滑價／市場衝擊；沒有 5／20 日重疊持倉模擬 |
| 每日校正 | 成熟預測到期評分，重新訓練與校準產生新版本；舊預測不可改寫 | 尚缺真實連續至少 60 個交易日、至少 500 筆一日到期預測的影子紀錄；歷史重播與合成資料不納入此紀錄 |
| 監控與營運 | 來源過期、外部特徵缺漏／過舊、簡單分布偏移、模型校驗與拒絕升級機制 | 尚缺各來源健康指標、分位數／分布漂移分析、分群校準、服務告警、排程重試／互斥鎖與供應商故障演練 |
| 原設計工具 | 使用可在本機驗證的 pandas、DuckDB、scikit-learn 與自行開發回測流程 | **尚未使用** LightGBM、CatBoost、Qlib、vectorbt、FinGPT、Optuna、MLflow；不能僅因文件提及而視為已整合 |

## 第一優先：資料與正確性

1. **取得可用的真實還原行情。** 驗收時列出所有股票與 0050 的起訖日、交易日數、缺漏率、來源及還原規則，至少核對分割、除息、停牌各一組案例；API 無權限或缺少還原價必須失敗並留下診斷。
2. **補齊研究股票池與十年跨度。** 對上市已滿十年的標的以實際日期跨度核對；較新公司只用真實可得歷史。擴充股票池須保存選樣規則、上市／下市期間與產業，不可依回測結果事後挑選。
3. **建立可稽核的歷史可用時間。** 每筆外部資料保存來源、會計／事件期間、原公告時間、實際收件時間及版本；以延遲公告、同日修正、隔日夜盤與休市案例驗收。單純將欄位改成 `observed` 不能構成證據。
4. **核對日曆與成分股。** 從已核實來源匯入開休市資料，驗證週末、國定休市及臨時休市。最新前十大與歷史前十大研究分開，後者必須有當時名單與權重。交易所休市資訊可由[臺灣證券交易所開休市日期表](https://www.twse.com.tw/zh/trading/holiday.html)核對。
5. **保持資料失敗時停止發報。** 驗收涵蓋憑證失效、配額耗盡、空回應、股票缺漏與資料過期；不得在未明示的情況下沿用過期資料或替換成其他來源。

## 第二優先：可行性與穩健性

1. 使用已實作的封存流程：研究預設預留最後 126 個市場交易日，凍結模型／特徵政策、程式與資料快照後，以 `holdout` 命令另行開封；既有結果直接讀取，不默默重新測試。需要十二個月等其他期間時，應在開封前約定。尚須取得合格真實資料並產生開封證據；開封後若依結果調整方法，同一期間就不能再稱為新方法的未觸碰保留集，應等待新的未來資料。
2. 各期間至少報告三折、126 個樣本外交易日的基準差異、Brier 分數、報酬誤差、區間涵蓋率與淨績效，並揭露多頭／空頭、股票、產業及流動性分群結果。
3. 以保留時間相依性的區塊自助抽樣，報告模型優勢與淨超額報酬的信賴區間；抽樣區塊長度、次數及接受門檻應在最終測試前約定。
4. 加入成本加倍、資料延遲、訊號缺漏與低流動性壓力情境；最大回撤、換手率及最低成交容量須符合事先約定的風險限制。
5. 固定資料／特徵政策後，累積至少 **60 個真實交易日、500 筆成熟的一日影子預測**。系統簽發時間應接近決策時間；重播、重複發報及改寫歷史預測不得增加樣本。逐日比較校準與區間涵蓋率，僅用已成熟標籤訓練新版本。
6. 完成故障告警、備份復原及候選／正式模型切換演練。升級門檻已要求封存保留測試通過；即使通過，也仍需上述穩健性分析，只能進入受追蹤預測，不代表自動下單授權。

## 第三優先：以增益決定新增模型

先用消融實驗依序加入大盤與個股殘差、法人、公告財報、夜盤／美股、新聞及產業特徵，再評估更複雜模型。每次只增加一類資料或一個方法，使用相同的時間切分、交易成本及比較基準。

只有在預先約定的樣本外指標改善、分群結果穩定、成本及維護負擔可接受時，才導入 LightGBM／CatBoost、正式分位數模型、SHAP、深度時序模型或 FinGPT。Optuna 的搜尋只能使用開發／驗證區間；MLflow 等追蹤工具可在實驗數量增加時加入。任何工具都不取代可靠資料與時間隔離。
